محاسن التأويل — القاسمي

وَحِفْظًا مِّن كُلِّ شَيْطَـٰنٍ مَّارِدٍ ﴿٧﴾

القَوْلُ في تَأْوِيلِ قَوْلِهِ تَعالى: [ ٧ ] ﴿وحِفْظًا مِن كُلِّ شَيْطانٍ مارِدٍ﴾ . ﴿وحِفْظًا مِن كُلِّ شَيْطانٍ مارِدٍ﴾ أيْ: خارِجٍ عَنِ اَلطّاعَةِ، يَقْذِفُهُ بِشُهُبِها، كَيْما يَتَطاوَلَ إلى اِسْتِراقِ اَلسَّمْعِ مِن جِهَتِها و: { حِفْظًا } إمّا مَنصُوبٌ بِإضْمارِ فِعْلِهِ؛ أيْ: حَفِظْناهُما حِفْظًا، أوْ بِعَطْفِهِ عَلى: { زِينَةٍ } مِن حَيْثُ اَلْمَعْنى؛ أيْ: خَلَقْنا اَلْكَواكِبَ لِلسَّماءِ زِينَةً وحِفْظًا، أوْ عَلى اَلْمَفْعُولِ لِأجْلِهِ بِزِيادَةِ اَلْواوِ، والعامِلُ فِيهِ: { زَيَّنّا } .
