يسالآية ٥٨

محاسن التأويل — القاسمي

سَلَـٰمٌ قَوْلًا مِّن رَّبٍّ رَّحِيمٍ ﴿٥٨﴾

القَوْلُ في تَأْوِيلِ قَوْلِهِ تَعالى: [ ٥٨ ] ﴿سَلامٌ قَوْلا مِن رَبٍّ رَحِيمٍ﴾ . ﴿سَلامٌ قَوْلا مِن رَبٍّ رَحِيمٍ﴾ أيْ: ولَهم سَلامٌ يُقالُ لَهم قَوْلًا كائِنًا مِنهُ تَعالى. فَيَكُونُ: { سَلامٌ } مُبْتَدَأٌ مَحْذُوفُ اَلْخَبَرِ، أوْ هو بَدَلٌ مِن: { ما } أوْ خَبَرٌ مَحْذُوفٌ، أيْ: هو سَلامٌ، أوْ مُبْتَدَأٌ خَبَرُهُ اَلنّاصِبُ لِـ: { قَوْلًا } أيْ: سَلامٌ يُقالُ لَهم قَوْلًا، أوْ مُبْتَدَأٌ وخَبَرُهُ: { مِن رَبٍّ } و: { قَوْلًا } مَصْدَرٌ مُؤَكِّدٌ لِمَضْمُونِ اَلْجُمْلَةِ، وهو مَعَ عامِلِهِ مُعْتَرِضٌ بَيْنَ اَلْمُبْتَدَأِ والخَبَرِ. والمَعْنى أنَّهُ تَعالى يُسَلِّمُ عَلَيْهِمْ تَعْظِيمًا لَهُمْ، كَقَوْلِهِ: ﴿تَحِيَّتُهم يَوْمَ يَلْقَوْنَهُ سَلامٌ﴾ [الأحزاب: ٤٤]
