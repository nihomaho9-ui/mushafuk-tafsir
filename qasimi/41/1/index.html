الآية ١

محاسن التأويل — القاسمي

بِسْمِ ٱللَّهِ ٱلرَّحْمَـٰنِ ٱلرَّحِيمِ حمٓ ﴿١﴾

(p-٥١٨٥)بِسْمِ اللَّهِ الرَّحْمَنِ الرَّحِيمِ سُورَةُ فُصِّلَتْ (حم السَّجْدَةِ) سُمِّيَتْ بِها لِاشْتِمالِها عَلى آيَةِ سَجْدَةٍ. تَدُلُّ عَلى بُطْلانِ عِبادَةِ المَظاهِرِ بِالكُلِّيَّةِ. وأنَّ اللَّهَ يَسْتَحِقُّ بِذاتِهِ أجَلَّ العِباداتِ. وهَذا مِن أعْظَمِ مَقاصِدِ القُرْآنِ. قالَهُ المَهايِمِيُّ. وهي مَكِّيَّةٌ. وآيُها أرْبَعٌ وخَمْسُونَ. (p-٥١٨٦)بِسْمِ اللَّهِ الرَّحْمَنِ الرَّحِيمِ القَوْلُ في تَأْوِيلِ قَوْلِهِ تَعالى: [ ١، ٢] ﴿حم﴾ ﴿تَنْـزِيلٌ مِنَ الرَّحْمَنِ الرَّحِيمِ﴾ [فصلت: ٢] . ﴿حم﴾ ﴿تَنْـزِيلٌ مِنَ الرَّحْمَنِ الرَّحِيمِ﴾ [فصلت: ٢] قالَ أبُو السُّعُودِ: إنْ جُعِلَ: { حم } اسْمًا لِلسُّورَةِ، فَهو إمّا خَبَرُ مُبْتَدَأٍ مَحْذُوفٍ، وهو الأظْهَرُ، أوْ مُبْتَدَأٌ خَبَرُهُ: { تَنْزِيلٌ } وهو عَلى الأوَّلِ خَبَرٌ بَعْدَ خَبَرٍ. وخَبَرٌ لِمُبْتَدَأٍ مَحْذُوفٍ، إنْ جُعِلَ مَسْرُودًا عَلى نَمَطِ التَّعْدِيدِ. وقَوْلُهُ تَعالى: ﴿مِنَ الرَّحْمَنِ الرَّحِيمِ﴾ [فصلت: ٢] مُتَعَلِّقٌ بِهِ، مُؤَكِّدٌ لِما أفادَهُ التَّنْوِينُ مِنَ الفَخامَةِ الذّاتِيَّةِ، بِالفَخامَةِ الإضافِيَّةِ. أوْ خَبَرٌ آخَرُ. أوْ: { تَنْزِيلٌ } مُبْتَدَأٌ لِتَخَصُّصِهِ بِالصِّفَةِ، خَبَرُهُ: ﴿كِتابٌ فُصِّلَتْ﴾ [فصلت: ٣]
