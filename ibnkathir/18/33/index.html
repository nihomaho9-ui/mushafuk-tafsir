الآية ٣٣

تفسير ابن كثير — ابن كثير

كِلْتَا ٱلْجَنَّتَيْنِ ءَاتَتْ أُكُلَهَا وَلَمْ تَظْلِم مِّنْهُ شَيْـًٔا ۚ وَفَجَّرْنَا خِلَـٰلَهُمَا نَهَرًا ﴿٣٣﴾

ولهذا قال : ( كلتا الجنتين آتت أكلها ) أي : خرجت ثمرها ( ولم تظلم منه شيئا ) أي : ولم تنقص منه شيئا ( وفجرنا خلالهما نهرا ) أي : والأنهار تتخرق فيهما هاهنا وهاهنا .
