الآية ٨١

تيسير الكريم الرحمن — السعدي

فَخَسَفْنَا بِهِۦ وَبِدَارِهِ ٱلْأَرْضَ فَمَا كَانَ لَهُۥ مِن فِئَةٍ يَنصُرُونَهُۥ مِن دُونِ ٱللَّهِ وَمَا كَانَ مِنَ ٱلْمُنتَصِرِينَ ﴿٨١﴾

فلما انتهت بقارون حالة البغي والفخر، وازَّيَّنَتْت الدنيا عنده، وكثر بها إعجابه، بغته العذاب { فَخَسَفْنَا بِهِ وَبِدَارِهِ الْأَرْضَ } جزاء من جنس عمله، فكما رفع نفسه على عباد اللّه، أنزله اللّه أسفل سافلين، هو وما اغتر به، من داره وأثاثه، ومتاعه.{ فَمَا كَانَ لَهُ مِنْ فِئَةٍ } أي: جماعة، وعصبة، وخدم، وجنود { يَنْصُرُونَهُ مِنْ دُونِ اللَّهِ وَمَا كَانَ مِنَ الْمُنْتَصِرِينَ } أي: جاءه العذاب، فما نصر ولا انتصر.
