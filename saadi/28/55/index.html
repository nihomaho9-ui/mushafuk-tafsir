القصصالآية ٥٥

تيسير الكريم الرحمن — السعدي

وَإِذَا سَمِعُوا۟ ٱللَّغْوَ أَعْرَضُوا۟ عَنْهُ وَقَالُوا۟ لَنَآ أَعْمَـٰلُنَا وَلَكُمْ أَعْمَـٰلُكُمْ سَلَـٰمٌ عَلَيْكُمْ لَا نَبْتَغِى ٱلْجَـٰهِلِينَ ﴿٥٥﴾

{ وَإِذَا سَمِعُوا اللَّغْوَ } من جاهل خاطبهم به، { قَالُوا } مقالة عباد الرحمن أولي الألباب: { لَنَا أَعْمَالُنَا وَلَكُمْ أَعْمَالُكُمْ } أي: كُلٌّ سَيُجازَى بعمله الذي عمله وحده، ليس عليه من وزر غيره شيء. ولزم من ذلك، أنهم يتبرءون مما عليه الجاهلون، من اللغو والباطل، والكلام الذي لا فائدة فيه.{ سَلَامٌ عَلَيْكُمْ } أي لا تسمعون منا إلا الخير، ولا نخاطبكم بمقتضى جهلكم، فإنكم وإن رضيتم لأنفسكم هذا المرتع اللئيم، فإننا ننزه أنفسنا عنه، ونصونها عن الخوض فيه، { لَا نَبْتَغِي الْجَاهِلِينَ } من كل وجه.
