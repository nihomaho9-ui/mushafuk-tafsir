تيسير الكريم الرحمن — السعدي

وَأَخِى هَـٰرُونُ هُوَ أَفْصَحُ مِنِّى لِسَانًا فَأَرْسِلْهُ مَعِىَ رِدْءًا يُصَدِّقُنِىٓ ۖ إِنِّىٓ أَخَافُ أَن يُكَذِّبُونِ ﴿٣٤﴾

} وَأَخِي هَارُونُ هُوَ أَفْصَحُ مِنِّي لِسَانًا فَأَرْسِلْهُ مَعِي رِدْءًا } أي: معاونا ومساعدا { يُصَدِّقُنِي } فإنه مع تضافر الأخبار يقوى الحق
