الآية ٦٤

تيسير الكريم الرحمن — السعدي

وَقِيلَ ٱدْعُوا۟ شُرَكَآءَكُمْ فَدَعَوْهُمْ فَلَمْ يَسْتَجِيبُوا۟ لَهُمْ وَرَأَوُا۟ ٱلْعَذَابَ ۚ لَوْ أَنَّهُمْ كَانُوا۟ يَهْتَدُونَ ﴿٦٤﴾

{ وَقِيلَ } لهم: { ادْعُوا شُرَكَاءَكُمْ } على ما أملتم فيهم من النفع فأمروا بدعائهم في ذلك الوقت الحرج، الذي يضطر فيه العابد إلى من عبده.{ فَدَعَوْهُمْ } لينفعوهم، أو يدفعوا عنهم من عذاب اللّه من شيء. { فَلَمْ يَسْتَجِيبُوا لَهُمْ } فعلم الذين كفروا أنهم كانوا كاذبين مستحقين للعقوبة، { وَرَأَوُا الْعَذَابَ } الذي سيحل بهم عيانا، بأبصارهم بعد ما كانوا مكذبين به، منكرين له.{ لَوْ أَنَّهُمْ كَانُوا يَهْتَدُونَ } أي: لما حصل عليهم ما حصل، ولهدوا إلى صراط الجنة، كما اهتدوا في الدنيا، ولكن لم يهتدوا، فلم يهتدوا.
