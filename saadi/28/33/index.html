تيسير الكريم الرحمن — السعدي

قَالَ رَبِّ إِنِّى قَتَلْتُ مِنْهُمْ نَفْسًا فَأَخَافُ أَن يَقْتُلُونِ ﴿٣٣﴾

فـ { قَالَ } موسى عليه السلام.معتذرا من ربه، وسائلا له المعونة على ما حمله، وذاكرا له الموانع التي فيه، ليزيل ربه ما يحذره منها. { رَبِّ إِنِّي قَتَلْتُ مِنْهُمْ نَفْسًا } أي: { فَأَخَافُ أَنْ يَقْتُلُونِ{
