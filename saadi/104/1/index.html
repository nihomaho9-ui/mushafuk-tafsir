تيسير الكريم الرحمن — السعدي

بِسْمِ ٱللَّهِ ٱلرَّحْمَـٰنِ ٱلرَّحِيمِ وَيْلٌ لِّكُلِّ هُمَزَةٍ لُّمَزَةٍ ﴿١﴾

{ وَيْلٌ } أي: وعيد، ووبال، وشدة عذاب { لِكُلِّ هُمَزَةٍ لُمَزَةٍ } الذي يهمز الناس بفعله، ويلمزهم بقوله، فالهماز: الذي يعيب الناس، ويطعن عليهم بالإشارة والفعل، واللماز: الذي يعيبهم بقوله.
