الآيات ١٧–١٨

تيسير الكريم الرحمن — السعدي

تَدْعُوا۟ مَنْ أَدْبَرَ وَتَوَلَّىٰ ﴿١٧﴾

وَجَمَعَ فَأَوْعَىٰٓ ﴿١٨﴾

الآيات ١٧–١٨{ تَدْعُوا } إليها { مَنْ أَدْبَرَ وَتَوَلَّى وجمع فأوعى } أي: أدبر عن اتباع الحق وأعرض عنه، فليس له فيه غرض، وجمع الأموال بعضها فوق بعض وأوعاها، فلم ينفق منها، فإن النار تدعوهم إلى نفسها، وتستعد للالتهاب بهم.
