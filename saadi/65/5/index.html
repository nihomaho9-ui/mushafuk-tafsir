الآية ٥

تيسير الكريم الرحمن — السعدي

ذَٰلِكَ أَمْرُ ٱللَّهِ أَنزَلَهُۥٓ إِلَيْكُمْ ۚ وَمَن يَتَّقِ ٱللَّهَ يُكَفِّرْ عَنْهُ سَيِّـَٔاتِهِۦ وَيُعْظِمْ لَهُۥٓ أَجْرًا ﴿٥﴾

{ ذَلِكَ } [أي:] الحكم الذي بينه الله لكم { أَمْرُ اللَّهِ أَنْزَلَهُ إِلَيْكُمْ } لتمشوا عليه، [وتأتموا] وتقوموا به وتعظموه.{ وَمَنْ يَتَّقِ اللَّهَ يُكَفِّرْ عَنْهُ سَيِّئَاتِهِ وَيُعْظِمْ لَهُ أَجْرًا } أي: يندفع عنه المحذور، ويحصل له المطلوب.
