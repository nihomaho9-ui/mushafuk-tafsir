الآية ٢٠

تيسير الكريم الرحمن — السعدي

ذِى قُوَّةٍ عِندَ ذِى ٱلْعَرْشِ مَكِينٍ ﴿٢٠﴾

{ ذِي قُوَّةٍ } على ما أمره الله به. ومن قوته أنه قلب ديار قوم لوط بهم فأهلكهم.{ عِنْدَ ذِي الْعَرْشِ } أي: جبريل مقرب عند الله، له منزلة رفيعة، وخصيصة من الله اختصه بها، { مَكِينٍ } أي: له مكانة ومنزلة فوق منازل الملائكة كلهم.
