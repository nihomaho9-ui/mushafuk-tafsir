الآية ٢٥

تيسير الكريم الرحمن — السعدي

مَّنَّاعٍ لِّلْخَيْرِ مُعْتَدٍ مُّرِيبٍ ﴿٢٥﴾

{ مَنَّاعٍ لِلْخَيْرِ } أي: يمنع الخير الذي عنده الذي أعظمه، الإيمان بالله [وملائكته] وتبه، ورسله مناع، لنفع ماله وبدنه، { مُعْتَدٍ } على عباد الله، وعلى حدوده { مُرِيبٍ } أي: شاك في وعد الله ووعيده، فلا إيمان ولا إحسان ولكن وصفه الكفر والعدوان، والشك والريب، والشح، واتخاذ الآلهة من دون الرحمن.
