الآيات ٤٢–٤٣

تيسير الكريم الرحمن — السعدي

يَوْمَ يَسْمَعُونَ ٱلصَّيْحَةَ بِٱلْحَقِّ ۚ ذَٰلِكَ يَوْمُ ٱلْخُرُوجِ ﴿٤٢﴾

إِنَّا نَحْنُ نُحْىِۦ وَنُمِيتُ وَإِلَيْنَا ٱلْمَصِيرُ ﴿٤٣﴾

الآيات ٤٢–٤٣{ يَوْمَ يَسْمَعُونَ الصَّيْحَةَ } أي: كل الخلائق يسمعون تلك الصيحة المزعجة المهولة { بالحق } الذي لا شك فيه ولا امتراء.{ ذَلِكَ يَوْمُ الْخُرُوجِ } من القبور، الذي انفرد به القادر على كل شيء.
