الآية ١٧

تيسير الكريم الرحمن — السعدي

إِذْ يَتَلَقَّى ٱلْمُتَلَقِّيَانِ عَنِ ٱلْيَمِينِ وَعَنِ ٱلشِّمَالِ قَعِيدٌ ﴿١٧﴾

{ إِذْ يَتَلَقَّى الْمُتَلَقِّيَانِ } أي: يتلقيان عن العبد أعماله كلها، واحد { عَنِ الْيَمِينِ } يكتب الحسنات { و } الآخر { عن الشِّمَالِ } يكتب السيئات، وكل منهما { قَعِيدٌ } بذلك متهيئ لعمله الذي أعد له، ملازم له
