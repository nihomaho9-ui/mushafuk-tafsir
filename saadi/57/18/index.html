الآية ١٨

تيسير الكريم الرحمن — السعدي

إِنَّ ٱلْمُصَّدِّقِينَ وَٱلْمُصَّدِّقَـٰتِ وَأَقْرَضُوا۟ ٱللَّهَ قَرْضًا حَسَنًا يُضَـٰعَفُ لَهُمْ وَلَهُمْ أَجْرٌ كَرِيمٌ ﴿١٨﴾

{ إِنَّ الْمُصَّدِّقِينَ وَالْمُصَّدِّقَاتِ } بالتشديد أي: الذين أكثروا من الصدقات الشرعية، والنفقات المرضية، { وَأَقْرَضُوا اللَّهَ قَرْضًا حَسَنًا } بأن قدموا من أموالهم في طرق الخيرات ما يكون مدخرا لهم عند ربهم، { يُضَاعَفُ لَهُمُ } الحسنة بعشر أمثالها إلى سبعمائة ضعف، إلى أضعاف كثيرة، { وَلَهُمْ أَجْرٌ كَرِيمٌ } وهو ما أعده الله لهم في الجنة، مما لا تعلمه النفوس.
