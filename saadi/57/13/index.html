الآية ١٣

تيسير الكريم الرحمن — السعدي

يَوْمَ يَقُولُ ٱلْمُنَـٰفِقُونَ وَٱلْمُنَـٰفِقَـٰتُ لِلَّذِينَ ءَامَنُوا۟ ٱنظُرُونَا نَقْتَبِسْ مِن نُّورِكُمْ قِيلَ ٱرْجِعُوا۟ وَرَآءَكُمْ فَٱلْتَمِسُوا۟ نُورًا فَضُرِبَ بَيْنَهُم بِسُورٍ لَّهُۥ بَابٌۢ بَاطِنُهُۥ فِيهِ ٱلرَّحْمَةُ وَظَـٰهِرُهُۥ مِن قِبَلِهِ ٱلْعَذَابُ ﴿١٣﴾

فإذا رأى المنافقون نور المؤمنين يمشون به وهم قد طفئ نورهم وبقوا في الظلمات حائرين، قالوا للمؤمنين: { انْظُرُونَا نَقْتَبِسْ مِنْ نُورِكُمْ } أي: أمهلونا لننال من نوركم ما نمشي به، لننجو من العذاب، فـ { قِيلَ } لهم: { ارْجِعُوا وَرَاءَكُمْ فَالْتَمِسُوا نُورًا } أي: إن كان ذلك ممكنا، والحال أن ذلك غير ممكن، بل هو من المحالات، { فَضُرِبَ } بين المؤمنين والمنافقين { بِسُورٍ } أي: حائط منيع، وحصن حصين، { لَهُ بَابٌ بَاطِنُهُ فِيهِ الرَّحْمَةُ } وهو الذي يلي المؤمنين { وَظَاهِرُهُ مِنْ قِبَلِهِ الْعَذَابُ } وهو الذي يلي المنافقين، فينادي المنافقون المؤمنين،
