الآية ١٥

تيسير الكريم الرحمن — السعدي

فَٱلْيَوْمَ لَا يُؤْخَذُ مِنكُمْ فِدْيَةٌ وَلَا مِنَ ٱلَّذِينَ كَفَرُوا۟ ۚ مَأْوَىٰكُمُ ٱلنَّارُ ۖ هِىَ مَوْلَىٰكُمْ ۖ وَبِئْسَ ٱلْمَصِيرُ ﴿١٥﴾

{ فَالْيَوْمَ لَا يُؤْخَذُ مِنْكُمْ فِدْيَةٌ وَلَا مِنَ الَّذِينَ كَفَرُوا } فلو افتديتم بمثل الأرض ذهبا ومثله معه، لما تقبل منكم، { مَأْوَاكُمُ النَّارُ } أي: مستقركم، { هِيَ مَوْلَاكُمْ } التي تتولاكم وتضمكم إليها، { وَبِئْسَ الْمَصِيرُ } النار.[قال تعالى:] { وَأَمَّا مَنْ خَفَّتْ مَوَازِينُهُ فَأُمُّهُ هَاوِيَةٌ وَمَا أَدْرَاكَ مَا هِيَهْ نَارٌ حَامِيَةٌ }
