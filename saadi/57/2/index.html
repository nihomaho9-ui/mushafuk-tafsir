الآية ٢

تيسير الكريم الرحمن — السعدي

لَهُۥ مُلْكُ ٱلسَّمَـٰوَٰتِ وَٱلْأَرْضِ ۖ يُحْىِۦ وَيُمِيتُ ۖ وَهُوَ عَلَىٰ كُلِّ شَىْءٍ قَدِيرٌ ﴿٢﴾

ثم أخبر عن عموم ملكه، فقال: { لَهُ مُلْكُ السَّمَاوَاتِ وَالْأَرْضِ يُحْيِي وَيُمِيتُ } أي: هو الخالق لذلك، الرازق المدبر لها بقدرته { وَهُوَ عَلَى كُلِّ شَيْءٍ قَدِيرٌ }
