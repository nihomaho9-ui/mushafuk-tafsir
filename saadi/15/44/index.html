الآية ٤٤

تيسير الكريم الرحمن — السعدي

لَهَا سَبْعَةُ أَبْوَٰبٍ لِّكُلِّ بَابٍ مِّنْهُمْ جُزْءٌ مَّقْسُومٌ ﴿٤٤﴾

{ لَهَا سَبْعَةُ أَبْوَابٍ } كل باب أسفل من الآخر، { لِكُلِّ بَابٍ مِنْهُمْ } أي: من أتباع إبليس { جُزْءٌ مَقْسُومٌ } بحسب أعمالهم. قال الله تعالى: { فَكُبْكِبُوا فِيهَا هُمْ وَالْغَاوُونَ وَجُنُودُ إِبْلِيسَ أَجْمَعُونَ }
