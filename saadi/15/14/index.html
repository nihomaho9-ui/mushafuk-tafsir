الآيات ١٤–١٥

تيسير الكريم الرحمن — السعدي

وَلَوْ فَتَحْنَا عَلَيْهِم بَابًا مِّنَ ٱلسَّمَآءِ فَظَلُّوا۟ فِيهِ يَعْرُجُونَ ﴿١٤﴾

لَقَالُوٓا۟ إِنَّمَا سُكِّرَتْ أَبْصَـٰرُنَا بَلْ نَحْنُ قَوْمٌ مَّسْحُورُونَ ﴿١٥﴾

الآيات ١٤–١٥أي: ولو جاءتهم كل آية عظيمة لم يؤمنوا وكابروا { ولو فتحنا عليهم بابا من السماء } فصاروا يعرجون فيه، ويشاهدونه عيانا بأنفسهم لقالوا من ظلمهم وعنادهم منكرين لهذه الآية: { إنما سكرت أبصارنا } أي: أصابها سكر وغشاوة حتى رأينا ما لم نر، { بل نحن قوم مسحورون } أي: ليس هذا بحقيقة، بل هذا سحر، وقوم وصلت بهم الحال إلى هذا الإنكار، فإنهم لا مطمع فيهم ولا رجاء
