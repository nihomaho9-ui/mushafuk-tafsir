الآيات ٥٩–٦٠

تيسير الكريم الرحمن — السعدي

إِلَّآ ءَالَ لُوطٍ إِنَّا لَمُنَجُّوهُمْ أَجْمَعِينَ ﴿٥٩﴾

إِلَّا ٱمْرَأَتَهُۥ قَدَّرْنَآ ۙ إِنَّهَا لَمِنَ ٱلْغَـٰبِرِينَ ﴿٦٠﴾

الآيات ٥٩–٦٠تفسير الآيتين 59 و 60 :ـ { إِلَّا آلَ لُوطٍ } أي: إلا لوطا وأهله { إِلَّا امْرَأَتَهُ قَدَّرْنَا إِنَّهَا لَمِنَ الْغَابِرِينَ } أي: الباقين بالعذاب، وأما لوط فسنخرجنه وأهله وننجيهم منها، فجعل إبراهيم يجادل الرسل في إهلاكهم ويراجعهم، فقيل له: { يا إبراهيم أعرض عن هذا إنه قد جاء أمر ربك وإنهم آتيهم عذاب غير مردود } فذهبوا منه.
