الآيات ٦١–٦٢

تيسير الكريم الرحمن — السعدي

فَلَمَّا جَآءَ ءَالَ لُوطٍ ٱلْمُرْسَلُونَ ﴿٦١﴾

قَالَ إِنَّكُمْ قَوْمٌ مُّنكَرُونَ ﴿٦٢﴾

الآيات ٦١–٦٢تفسير الآيتين 61 و 62 :ـ { فَلَمَّا جَاءَ آلَ لُوطٍ الْمُرْسَلُونَ قَالَ } لهم لوط { إِنَّكُمْ قَوْمٌ مُنْكَرُونَ } أي: لا أعرفكم ولا أدري من أنتم.
