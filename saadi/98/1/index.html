الآية ١

تيسير الكريم الرحمن — السعدي

بِسْمِ ٱللَّهِ ٱلرَّحْمَـٰنِ ٱلرَّحِيمِ لَمْ يَكُنِ ٱلَّذِينَ كَفَرُوا۟ مِنْ أَهْلِ ٱلْكِتَـٰبِ وَٱلْمُشْرِكِينَ مُنفَكِّينَ حَتَّىٰ تَأْتِيَهُمُ ٱلْبَيِّنَةُ ﴿١﴾

يقول تعالى: { لَمْ يَكُنِ الَّذِينَ كَفَرُوا مِنْ أَهْلِ الْكِتَابِ } أي: [من] اليهود والنصارى { وَالْمُشْرِكِينَ } من سائر أصناف الأمم.{ مُنْفَكِّينَ } عن كفرهم وضلالهم الذي هم عليه، أي: لا يزالون في غيهم وضلالهم، لا يزيدهم مرور السنين إلا كفرًا.{ حَتَّى تَأْتِيَهُمُ الْبَيِّنَةُ } الواضحة، والبرهان الساطع.
