الآية ٨٧

تيسير الكريم الرحمن — السعدي

وَأَوْحَيْنَآ إِلَىٰ مُوسَىٰ وَأَخِيهِ أَن تَبَوَّءَا لِقَوْمِكُمَا بِمِصْرَ بُيُوتًا وَٱجْعَلُوا۟ بُيُوتَكُمْ قِبْلَةً وَأَقِيمُوا۟ ٱلصَّلَوٰةَ ۗ وَبَشِّرِ ٱلْمُؤْمِنِينَ ﴿٨٧﴾

{ وَأَوْحَيْنَا إِلَى مُوسَى وَأَخِيهِ } حين اشتد الأمر على قومهما، من فرعون وقومه، وحرصوا على فتنتهم عن دينهم. { أَنْ تَبَوَّآ لِقَوْمِكُمَا بِمِصْرَ بُيُوتًا } أي: مروهم أن يجعلوا لهم بيوتًا، يتمكنون به من الاستخفاء فيها. { وَاجْعَلُوا بُيُوتَكُمْ قِبْلَةً } أي: اجعلوها محلا، تصلون فيها، حيث عجزتم عن إقامة الصلاة في الكنائس، والبيع العامة. { وَأَقِيمُوا الصَّلَاةَ } فإنها معونة على جميع الأمور، { وَبَشِّرِ الْمُؤْمِنِينَ } بالنصر والتأييد، وإظهار دينهم، فإن مع العسر يسرًا، إن مع العسر يسرًا، وحين اشتد الكرب، وضاق الأمر، فرجه الله ووسعه.فلما رأى موسى، القسوة والإعراض من فرعون وملئه ، دعا عليهم وأمن هارون على دعائه.
