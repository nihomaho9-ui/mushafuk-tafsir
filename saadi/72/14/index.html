الآية ١٤

تيسير الكريم الرحمن — السعدي

وَأَنَّا مِنَّا ٱلْمُسْلِمُونَ وَمِنَّا ٱلْقَـٰسِطُونَ ۖ فَمَنْ أَسْلَمَ فَأُو۟لَـٰٓئِكَ تَحَرَّوْا۟ رَشَدًا ﴿١٤﴾

{ وَأَنَّا مِنَّا الْمُسْلِمُونَ وَمِنَّا الْقَاسِطُونَ } أي: الجائرون العادلون عن الصراط المستقيم.{ فَمَنْ أَسْلَمَ فَأُولَئِكَ تَحَرَّوْا رَشَدًا } أي:: أصابوا طريق الرشد، الموصل لهم إلى الجنة ونعيمها،
