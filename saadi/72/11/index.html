تيسير الكريم الرحمن — السعدي

وَأَنَّا مِنَّا ٱلصَّـٰلِحُونَ وَمِنَّا دُونَ ذَٰلِكَ ۖ كُنَّا طَرَآئِقَ قِدَدًا ﴿١١﴾

{ وَأَنَّا مِنَّا الصَّالِحُونَ وَمِنَّا دُونَ ذَلِكَ } أي: فساق وفجار وكفار، { كُنَّا طَرَائِقَ قِدَدًا } أي: فرقا متنوعة، وأهواء متفرقة، كل حزب بما لديهم فرحون.
