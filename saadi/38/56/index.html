الآية ٥٦

تيسير الكريم الرحمن — السعدي

جَهَنَّمَ يَصْلَوْنَهَا فَبِئْسَ ٱلْمِهَادُ ﴿٥٦﴾

ثم فصله فقال: { جَهَنَّمَ } التي جمع فيها كل عذاب، واشتد حرها، وانتهى قرها { يَصْلَوْنَهَا } أي: يعذبون فيها عذابا يحيط بهم من كل وجه، لهم من فوقهم ظلل من النار ومن تحتهم ظلل.{ فَبِئْسَ الْمِهَادُ } المعد لهم مسكنا ومستقرا.
