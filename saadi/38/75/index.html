تيسير الكريم الرحمن — السعدي

قَالَ يَـٰٓإِبْلِيسُ مَا مَنَعَكَ أَن تَسْجُدَ لِمَا خَلَقْتُ بِيَدَىَّ ۖ أَسْتَكْبَرْتَ أَمْ كُنتَ مِنَ ٱلْعَالِينَ ﴿٧٥﴾

فـ { قَالَ } اللّه موبخا ومعاتبا: { مَا مَنَعَكَ أَنْ تَسْجُدَ لِمَا خَلَقْتُ بِيَدَيَّ } أي: شرفته وكرمته واختصصته بهذه الخصيصة، التي اختص بها عن سائر الخلق، وذلك يقتضي عدم التكبر عليه.{ أسْتَكْبَرْتَ } في امتناعك { أَمْ كُنْتَ مِنَ الْعَالِينَ }
