الآية ٢٥

تيسير الكريم الرحمن — السعدي

فَغَفَرْنَا لَهُۥ ذَٰلِكَ ۖ وَإِنَّ لَهُۥ عِندَنَا لَزُلْفَىٰ وَحُسْنَ مَـَٔابٍ ﴿٢٥﴾

{ فَغَفَرْنَا لَهُ ذَلِكَ } الذي صدر منه، وأكرمه اللّه بأنواع الكرامات، فقال: { وَإِنَّ لَهُ عِنْدَنَا لَزُلْفَى } أي: منزلة عالية، وقربة منا، { وَحُسْنَ مَآبٍ } أي: مرجع.وهذا الذنب الذي صدر من داود عليه السلام، لم يذكره اللّه لعدم الحاجة إلى ذكره، فالتعرض له من باب التكلف، وإنما الفائدة ما قصه اللّه علينا من لطفه به وتوبته وإنابته، وأنه ارتفع محله، فكان بعد التوبة أحسن منه قبلها.
