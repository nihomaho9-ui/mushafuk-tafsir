الآية ٥٩

تيسير الكريم الرحمن — السعدي

هَـٰذَا فَوْجٌ مُّقْتَحِمٌ مَّعَكُمْ ۖ لَا مَرْحَبًۢا بِهِمْ ۚ إِنَّهُمْ صَالُوا۟ ٱلنَّارِ ﴿٥٩﴾

وعند تواردهم على النار يشتم بعضهم بعضا، ويقول بعضهم لبعض: { هَذَا فَوْجٌ مُقْتَحِمٌ مَعَكُمْ } النار { لَا مَرْحَبًا بِهِمْ إِنَّهُمْ صَالُوا النَّارِ }
