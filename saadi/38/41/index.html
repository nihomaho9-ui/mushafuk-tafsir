الآية ٤١

تيسير الكريم الرحمن — السعدي

وَٱذْكُرْ عَبْدَنَآ أَيُّوبَ إِذْ نَادَىٰ رَبَّهُۥٓ أَنِّى مَسَّنِىَ ٱلشَّيْطَـٰنُ بِنُصْبٍ وَعَذَابٍ ﴿٤١﴾

أي: { وَاذْكُرْ } في هذا الكتاب ذي الذكر { عَبْدَنَا أَيُّوبَ } بأحسن الذكر، وأثن عليه بأحسن الثناء، حين أصابه الضر، فصبر على ضره، فلم يشتك لغير ربه، ولا لجأ إلا إليه.فـ { نَادَى رَبَّهُ } داعيا، وإليه لا إلى غيره شاكيا، فقال: رب { أَنِّي مَسَّنِيَ الشَّيْطَانُ بِنُصْبٍ وَعَذَابٍ } أي: بأمر مشق متعب معذب، وكان سلط على جسده فنفخ فيه حتى تقرح، ثم تقيح بعد ذلك واشتد به الأمر، وكذلك هلك أهله وماله.
