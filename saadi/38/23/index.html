الآية ٢٣

تيسير الكريم الرحمن — السعدي

إِنَّ هَـٰذَآ أَخِى لَهُۥ تِسْعٌ وَتِسْعُونَ نَعْجَةً وَلِىَ نَعْجَةٌ وَٰحِدَةٌ فَقَالَ أَكْفِلْنِيهَا وَعَزَّنِى فِى ٱلْخِطَابِ ﴿٢٣﴾

فقال أحدهما: { إِنَّ هَذَا أَخِي } نص على الأخوة في الدين أو النسب أو الصداقة، لاقتضائها عدم البغي، وأن بغيه الصادر منه أعظم من غيره. { لَهُ تِسْعٌ وَتِسْعُونَ نَعْجَةً } أي: زوجة، وذلك خير كثير، يوجب عليه القناعة بما آتاه اللّه.{ وَلِيَ نَعْجَةٌ وَاحِدَةٌ } فطمع فيها { فَقَالَ أَكْفِلْنِيهَا } أي: دعها لي، وخلها في كفالتي. { وَعَزَّنِي فِي الْخِطَابِ } أي: غلبني في القول، فلم يزل بي حتى أدركها أو كاد.
