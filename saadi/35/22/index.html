الآية ٢٢

تيسير الكريم الرحمن — السعدي

وَمَا يَسْتَوِى ٱلْأَحْيَآءُ وَلَا ٱلْأَمْوَٰتُ ۚ إِنَّ ٱللَّهَ يُسْمِعُ مَن يَشَآءُ ۖ وَمَآ أَنتَ بِمُسْمِعٍ مَّن فِى ٱلْقُبُورِ ﴿٢٢﴾

{ إِنَّ اللَّهَ يُسْمِعُ مَنْ يَشَاءُ } سماع فهم وقبول، لأنه تعالى هو الهادي الموفق { وَمَا أَنْتَ بِمُسْمِعٍ مَنْ فِي الْقُبُورِ } أي: أموات القلوب، أو كما أن دعاءك لا يفيد سكان القبور شيئا، كذلك لا يفيد المعرض المعاند شيئا، ولكن وظيفتك النذارة، وإبلاغ ما أرسلت به، قبل منك أم لا.
