تيسير الكريم الرحمن — السعدي

إِنَّا جَعَلْنَـٰهُ قُرْءَٰنًا عَرَبِيًّا لَّعَلَّكُمْ تَعْقِلُونَ ﴿٣﴾

{ إِنَّا جَعَلْنَاهُ قُرْآنًا عَرَبِيًّا } هذا المقسم عليه، أنه جعل بأفصح اللغات وأوضحها وأبينها، وهذا من بيانه. وذكر الحكمة في ذلك فقال: { لَعَلَّكُمْ تَعْقِلُونَ } ألفاظه ومعانيه لتيسرها وقربها من الأذهان.
