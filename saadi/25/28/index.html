الآية ٢٨

تيسير الكريم الرحمن — السعدي

يَـٰوَيْلَتَىٰ لَيْتَنِى لَمْ أَتَّخِذْ فُلَانًا خَلِيلًا ﴿٢٨﴾

{ يَا وَيْلَتَى لَيْتَنِي لَمْ أَتَّخِذْ فُلَانًا } وهو الشيطان الإنسي أو الجني، { خَلِيلًا } أي: حبيبا مصافيا عاديت أنصح الناس لي، وأبرهم بي وأرفقهم بي، وواليت أعدى عدو لي الذي لم تفدني ولايته إلا الشقاء والخسار والخزي والبوار.
