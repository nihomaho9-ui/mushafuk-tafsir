الآية ٨١

تيسير الكريم الرحمن — السعدي

وَلِسُلَيْمَـٰنَ ٱلرِّيحَ عَاصِفَةً تَجْرِى بِأَمْرِهِۦٓ إِلَى ٱلْأَرْضِ ٱلَّتِى بَـٰرَكْنَا فِيهَا ۚ وَكُنَّا بِكُلِّ شَىْءٍ عَـٰلِمِينَ ﴿٨١﴾

{ وَلِسُلَيْمَانَ الرِّيحَ } أي: سخرناها { عَاصِفَةً } أي: سريعة في مرورها، { تَجْرِي بِأَمْرِهِ } حيث دبرت امتثلت أمره، غدوها شهر ورواحها شهر { إِلَى الْأَرْضِ الَّتِي بَارَكْنَا فِيهَا } وهي أرض الشام، حيث كان مقره، فيذهب على الريح شرقا وغربا، ويكون مأواها ورجوعها إلى الأرض المباركة، { وَكُنَّا بِكُلِّ شَيْءٍ عَالِمِينَ } قد أحاط علمنا بجميع الأشياء، وعلمنا من داود وسليمان، ما أوصلناهما به إلى ما ذكرنا.
