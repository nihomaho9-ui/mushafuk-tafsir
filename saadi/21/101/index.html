الآية ١٠١

تيسير الكريم الرحمن — السعدي

إِنَّ ٱلَّذِينَ سَبَقَتْ لَهُم مِّنَّا ٱلْحُسْنَىٰٓ أُو۟لَـٰٓئِكَ عَنْهَا مُبْعَدُونَ ﴿١٠١﴾

تفسير الآيتين 101 و102 :ـ وأما المسيح، وعزير، والملائكة ونحوهم، ممن عبد من الأولياء، فإنهم لا يعذبون فيها، ويدخلون في قوله: { إِنَّ الَّذِينَ سَبَقَتْ لَهُمْ مِنَّا الْحُسْنَى } أي: سبقت لهم سابقة السعادة في علم الله، وفي اللوح المحفوظ وفي تيسيرهم في الدنيا لليسرى والأعمال الصالحة. { أُولَئِكَ عَنْهَا } أي: عن النار { مُبْعَدُونَ } فلا يدخلونها، ولا يكونون قريبا منها، بل يبعدون عنها، غاية البعد، حتى لا يسمعوا حسيسها، ولا يروا شخصها، { وَهُمْ فِي مَا اشْتَهَتْ أَنْفُسُهُمْ خَالِدُونَ } من المآكل، والمشارب، والمناكح والمناظر، مما لا عين رأت، ولا أذن سمعت، ولا خطر على قلب بشر، مستمر لهم ذلك، يزداد حسنه على الأحقاب.
