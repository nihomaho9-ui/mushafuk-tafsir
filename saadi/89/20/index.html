الآية ٢٠

تيسير الكريم الرحمن — السعدي

وَتُحِبُّونَ ٱلْمَالَ حُبًّا جَمًّا ﴿٢٠﴾

{ وَتُحِبُّونَ الْمَالَ حُبًّا جَمًّا } أي: كثيرًا شديدًا، وهذا كقوله تعالى: { بَلْ تُؤْثِرُونَ الْحَيَاةَ الدُّنْيَا وَالْآخِرَةُ خَيْرٌ وَأَبْقَى } { كَلَّا بَلْ تُحِبُّونَ الْعَاجِلَةَ وَتَذَرُونَ الْآخِرَةَ } .
