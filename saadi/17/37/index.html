الإسراءالآية ٣٧

تيسير الكريم الرحمن — السعدي

وَلَا تَمْشِ فِى ٱلْأَرْضِ مَرَحًا ۖ إِنَّكَ لَن تَخْرِقَ ٱلْأَرْضَ وَلَن تَبْلُغَ ٱلْجِبَالَ طُولًا ﴿٣٧﴾

يقول تعالى: { وَلَا تَمْشِ فِي الْأَرْضِ مَرَحًا } أي: كبرا وتيها وبطرا متكبرا على الحق ومتعاظما على الخلق. { إِنَّكَ } في فعلك ذلك { لَنْ تَخْرِقَ الْأَرْضَ وَلَنْ تَبْلُغَ الْجِبَالَ طُولًا } في تكبرك بل تكون حقيرا عند الله ومحتقرا عند الخلق مبغوضا ممقوتا قد اكتسبت أشر الأخلاق واكتسيت أرذلها من غير إدراك لبعض ما تروم.
