الآية ٦٩

تيسير الكريم الرحمن — السعدي

أَمْ أَمِنتُمْ أَن يُعِيدَكُمْ فِيهِ تَارَةً أُخْرَىٰ فَيُرْسِلَ عَلَيْكُمْ قَاصِفًا مِّنَ ٱلرِّيحِ فَيُغْرِقَكُم بِمَا كَفَرْتُمْ ۙ ثُمَّ لَا تَجِدُوا۟ لَكُمْ عَلَيْنَا بِهِۦ تَبِيعًا ﴿٦٩﴾

وإن ظننتم ذلك فأنتم آمنون من { أَنْ يُعِيدَكُمْ } في البحر { تَارَةً أُخْرَى فَيُرْسِلَ عَلَيْكُمْ قَاصِفًا مِنَ الرِّيحِ } أي: ريحا شديدة جدا تقصف ما أتت عليه. { فَيُغْرِقَكُمْ بِمَا كَفَرْتُمْ ثُمَّ لَا تَجِدُوا لَكُمْ عَلَيْنَا بِهِ تَبِيعًا } أي: تبعة ومطالبة فإن الله لم يظلمكم مثقال ذرة.
