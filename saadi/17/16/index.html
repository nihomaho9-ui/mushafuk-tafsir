الآية ١٦

تيسير الكريم الرحمن — السعدي

وَإِذَآ أَرَدْنَآ أَن نُّهْلِكَ قَرْيَةً أَمَرْنَا مُتْرَفِيهَا فَفَسَقُوا۟ فِيهَا فَحَقَّ عَلَيْهَا ٱلْقَوْلُ فَدَمَّرْنَـٰهَا تَدْمِيرًا ﴿١٦﴾

يخبر تعالى أنه إذا أراد أن يهلك قرية من القرى الظالمة ويستأصلها بالعذاب أمر مترفيها أمرا قدريا ففسقوا فيها واشتد طغيانهم، { فَحَقَّ عَلَيْهَا الْقَوْلُ } أي: كلمة العذاب التي لا مرد لها { فَدَمَّرْنَاهَا تَدْمِيرًا }
