الآية ٧

تيسير الكريم الرحمن — السعدي

إِنْ أَحْسَنتُمْ أَحْسَنتُمْ لِأَنفُسِكُمْ ۖ وَإِنْ أَسَأْتُمْ فَلَهَا ۚ فَإِذَا جَآءَ وَعْدُ ٱلْـَٔاخِرَةِ لِيَسُـۥٓـُٔوا۟ وُجُوهَكُمْ وَلِيَدْخُلُوا۟ ٱلْمَسْجِدَ كَمَا دَخَلُوهُ أَوَّلَ مَرَّةٍ وَلِيُتَبِّرُوا۟ مَا عَلَوْا۟ تَتْبِيرًا ﴿٧﴾

{ إِنْ أَحْسَنْتُمْ أَحْسَنْتُمْ لِأَنْفُسِكُمْ } لأن النفع عائد إليكم حتى في الدنيا كما شاهدتم من انتصاركم على أعدائكم. { وَإِنْ أَسَأْتُمْ فَلَهَا } أي: فلأنفسكم يعود الضرر كما أراكم الله من تسليط الأعداء. { فَإِذَا جَاءَ وَعْدُ الْآخِرَةِ } أي: المرة الآخرة التي تفسدون فيها في الأرض سلطنا عليكم الأعداء. { لِيَسُوءُوا وُجُوهَكُمْ } بانتصارهم عليكم وسبيكم وليدخلوا المسجد الحرام كما دخلوه أول مرة، والمراد بالمسجد مسجد بيت المقدس. { وَلِيُتَبِّرُوا } أي: يخربوا ويدمروا { مَا عَلَوْا } عليه { تَتْبِيرًا } فيخربوا بيوتكم ومساجدكم وحروثكم.
