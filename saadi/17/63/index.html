الآية ٦٣

تيسير الكريم الرحمن — السعدي

قَالَ ٱذْهَبْ فَمَن تَبِعَكَ مِنْهُمْ فَإِنَّ جَهَنَّمَ جَزَآؤُكُمْ جَزَآءً مَّوْفُورًا ﴿٦٣﴾

فقال الله له: { اذْهَبْ فَمَنْ تَبِعَكَ مِنْهُمْ } واختارك على ربه ووليه الحق، { فَإِنَّ جَهَنَّمَ جَزَاؤُكُمْ جَزَاءً مَوْفُورًا } أي: مدخرا لكم موفرا جزاء أعمالكم.
