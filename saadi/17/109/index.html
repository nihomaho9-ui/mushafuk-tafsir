الآية ١٠٩

تيسير الكريم الرحمن — السعدي

وَيَخِرُّونَ لِلْأَذْقَانِ يَبْكُونَ وَيَزِيدُهُمْ خُشُوعًا ۩ ﴿١٠٩﴾

{ وَيَخِرُّونَ لِلْأَذْقَانِ } أي: على وجوههم { يَبْكُونَ وَيَزِيدُهُمْ } القرآن { خُشُوعًا } وهؤلاء كالذين من الله عليهم من مؤمني أهل الكتاب كعبد الله ابن سلام وغيره، ممن آمن في وقت النبي صلى الله عليه وسلم وبعد ذلك.
