الآية ٧٤

تيسير الكريم الرحمن — السعدي

وَلَوْلَآ أَن ثَبَّتْنَـٰكَ لَقَدْ كِدتَّ تَرْكَنُ إِلَيْهِمْ شَيْـًٔا قَلِيلًا ﴿٧٤﴾

{ وَ } مع هذا فـ { لَوْلَا أَنْ ثَبَّتْنَاكَ } على الحق، وامتننا عليك بعدم الإجابة لداعيهم، { لَقَدْ كِدْتَ تَرْكَنُ إِلَيْهِمْ شَيْئًا قَلِيلًا } من كثرة المعالجة، ومحبتك لهدايتهم.
