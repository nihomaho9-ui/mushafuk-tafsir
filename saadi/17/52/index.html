الآية ٥٢

تيسير الكريم الرحمن — السعدي

يَوْمَ يَدْعُوكُمْ فَتَسْتَجِيبُونَ بِحَمْدِهِۦ وَتَظُنُّونَ إِن لَّبِثْتُمْ إِلَّا قَلِيلًا ﴿٥٢﴾

{ يَوْمَ يَدْعُوكُمْ } للبعث والنشور وينفخ في الصور { فَتَسْتَجِيبُونَ بِحَمْدِهِ } أي: تنقادون لأمره ولا تستعصون عليه. وقوله: { بحمده } أي: هو المحمود تعالى على فعله ويجزي به العباد إذا جمعهم ليوم التناد. { وَتَظُنُّونَ إِنْ لَبِثْتُمْ إِلَّا قَلِيلًا } من سرعة وقوعه وأن الذي مر عليكم من النعيم كأنه ما كان. فهذا الذي يقول عنه المنكرون: { متى هو } ؟ يندمون غاية الندم عند وروده ويقال لهم: { هذا الذي كنتم به تكذبون }
