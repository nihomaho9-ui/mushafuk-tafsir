تيسير الكريم الرحمن — السعدي

فَعَتَوْا۟ عَنْ أَمْرِ رَبِّهِمْ فَأَخَذَتْهُمُ ٱلصَّـٰعِقَةُ وَهُمْ يَنظُرُونَ ﴿٤٤﴾

[ فَعَتَوْا عَنْ أَمْرِ رَبِّهِمْ فَأَخَذَتْهُمُ الصَّاعِقَةُ } أي: الصيحة العظيمة المهلكة { وَهُمْ يَنْظُرُونَ } إلى عقوبتهم بأعينهم.
