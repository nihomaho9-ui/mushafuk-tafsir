سبأالآية ٢

تيسير الكريم الرحمن — السعدي

يَعْلَمُ مَا يَلِجُ فِى ٱلْأَرْضِ وَمَا يَخْرُجُ مِنْهَا وَمَا يَنزِلُ مِنَ ٱلسَّمَآءِ وَمَا يَعْرُجُ فِيهَا ۚ وَهُوَ ٱلرَّحِيمُ ٱلْغَفُورُ ﴿٢﴾

{ يَعْلَمُ مَا يَلِجُ فِي الْأَرْضِ } أي: من مطر, وبذر, وحيوان { وَمَا يَخْرُجُ مِنْهَا } من أنواع النباتات, وأصناف الحيوانات { وَمَا يَنْزِلُ مِنَ السَّمَاءِ } من الأملاك والأرزاق والأقدار { وَمَا يَعْرُجُ فِيهَا } من الملائكة والأرواح وغير ذلك.ولما ذكر مخلوقاته وحكمته فيها, وعلمه بأحوالها, ذكر مغفرته ورحمته لها, فقال: { وَهُوَ الرَّحِيمُ الْغَفُورُ } أي: الذي الرحمة والمغفرة وصفه, ولم تزل آثارهما تنزل على عباده كل وقت بحسب ما قاموا به من مقتضياتهما.
