تيسير الكريم الرحمن — السعدي

وَلَوْ أَلْقَىٰ مَعَاذِيرَهُۥ ﴿١٥﴾

{ وَلَوْ أَلْقَى مَعَاذِيرَهُ } فإنها معاذير لا تقبل، ولا تقابل ما يقرر به العبد ، فيقر به، كما قال تعالى: { اقْرَأْ كِتَابَكَ كَفَى بِنَفْسِكَ الْيَوْمَ عَلَيْكَ حَسِيبًا } . فالعبد وإن أنكر، أو اعتذر عما عمله، فإنكاره واعتذاره لا يفيدانه شيئا، لأنه يشهد عليه سمعه وبصره، وجميع جوارحه بما كان يعمل، ولأن استعتابه قد ذهب وقته وزال نفعه: { فَيَوْمَئِذٍ لَا يَنْفَعُ الَّذِينَ ظَلَمُوا مَعْذِرَتُهُمْ وَلَا هُمْ يُسْتَعْتَبُونَ }
