الآية ٣١

تيسير الكريم الرحمن — السعدي

مِن فِرْعَوْنَ ۚ إِنَّهُۥ كَانَ عَالِيًا مِّنَ ٱلْمُسْرِفِينَ ﴿٣١﴾

{ مِنْ فِرْعَوْنَ } إذ يذبح أبناءهم ويستحيي نساءهم. { إِنَّهُ كَانَ عَالِيًا } أي: مستكبرا في الأرض بغير الحق { مِنَ الْمُسْرِفِينَ } المتجاوزين لحدود الله المتجرئين على محارمه.
