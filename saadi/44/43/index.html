الدخانالآية ٤٣

تيسير الكريم الرحمن — السعدي

إِنَّ شَجَرَتَ ٱلزَّقُّومِ ﴿٤٣﴾

الآيات ٤٣–٤٤لما ذكر يوم القيامة وأنه يفصل بين عباده فيه ذكر افتراقهم إلى فريقين: فريق في الجنة، وفريق في السعير وهم: الآثمون بعمل الكفر والمعاصي وأن طعامهم { شَجَرَةَ الزَّقُّومِ } شر الأشجار وأفظعها وأن طعمها { كَالْمُهْلِ }
