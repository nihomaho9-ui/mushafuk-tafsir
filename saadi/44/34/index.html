الآية ٣٤

تيسير الكريم الرحمن — السعدي

إِنَّ هَـٰٓؤُلَآءِ لَيَقُولُونَ ﴿٣٤﴾

يخبر تعالى { إِنَّ هَؤُلَاءِ } المكذبين يقولون مستبعدين للبعث والنشور: { إِنْ هِيَ إِلَّا مَوْتَتُنَا الْأُولَى وَمَا نَحْنُ بِمُنْشَرِينَ } أي: ما هي إلا الحياة الدنيا فلا بعث ولا نشور ولا جنة ولا نار.
