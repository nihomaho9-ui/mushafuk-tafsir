الآية ٢٢

تيسير الكريم الرحمن — السعدي

إِنَّ هَـٰذَا كَانَ لَكُمْ جَزَآءً وَكَانَ سَعْيُكُم مَّشْكُورًا ﴿٢٢﴾

{ إِنَّ هَذَا } الجزاء الجزيل والعطاء الجميل { كَانَ لَكُمْ جَزَاءً } على ما أسلفتموه من الأعمال، { وَكَانَ سَعْيُكُمْ مَشْكُورًا } أي: القليل منه، يجعل الله لكم به من النعيم المقيم ما لا يمكن حصره.
