تيسير الكريم الرحمن — السعدي

يُدْخِلُ مَن يَشَآءُ فِى رَحْمَتِهِۦ ۚ وَٱلظَّـٰلِمِينَ أَعَدَّ لَهُمْ عَذَابًا أَلِيمًۢا ﴿٣١﴾

{ يُدْخِلُ مَنْ يَشَاءُ فِي رَحْمَتِهِ } فيختصه بعنايته، ويوفقه لأسباب السعادة ويهديه لطرقها. { وَالظَّالِمِينَ } الذين اختاروا الشقاء على الهدى { أَعَدَّ لَهُمْ عَذَابًا أَلِيمًا } بظلمهم وعدوانهم .تم تفسير سورة الإنسان - ولله الحمد والمنة
