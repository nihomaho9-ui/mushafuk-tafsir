النبأالآية ٣٥

تيسير الكريم الرحمن — السعدي

لَّا يَسْمَعُونَ فِيهَا لَغْوًا وَلَا كِذَّٰبًا ﴿٣٥﴾

{ لَا يَسْمَعُونَ فِيهَا لَغْوًا } أي: كلاما لا فائدة فيه { وَلَا كِذَّابًا } أي: إثما.كما قال تعالى: { لَا يَسْمَعُونَ فِيهَا لَغْوًا وَلَا تَأْثِيمًا إِلَّا قِيلًا سَلَامًا سَلَامًا }
