تيسير الكريم الرحمن — السعدي

إِنَّ بَطْشَ رَبِّكَ لَشَدِيدٌ ﴿١٢﴾

{ إِنَّ بَطْشَ رَبِّكَ لَشَدِيدٌ } أي: إن عقوبته لأهل الجرائم والذنوب العظام [لقوية] شديدة، وهو بالمرصاد للظالمين كما قال الله تعالى: { وَكَذَلِكَ أَخْذُ رَبِّكَ إِذَا أَخَذَ الْقُرَى وَهِيَ ظَالِمَةٌ إِنَّ أَخْذَهُ أَلِيمٌ شَدِيدٌ }
