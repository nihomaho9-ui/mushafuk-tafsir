الآية ٢٨

تيسير الكريم الرحمن — السعدي

هُوَ ٱلَّذِىٓ أَرْسَلَ رَسُولَهُۥ بِٱلْهُدَىٰ وَدِينِ ٱلْحَقِّ لِيُظْهِرَهُۥ عَلَى ٱلدِّينِ كُلِّهِۦ ۚ وَكَفَىٰ بِٱللَّهِ شَهِيدًا ﴿٢٨﴾

أخبر بحكم عام، فقال: { هُوَ الَّذِي أَرْسَلَ رَسُولَهُ بِالْهُدَى } الذي هو العلم النافع، الذي يهدي من الضلالة، ويبين طرق الخير والشر.{ وَدِينِ الْحَقِّ } أي: الدين الموصوف بالحق، وهو العدل والإحسان والرحمة.وهو كل عمل صالح مزك للقلوب، مطهر للنفوس، مرب للأخلاق، معل للأقدار.{ لِيُظْهِرَهُ } بما بعثه الله به { عَلَى الدِّينِ كُلِّهِ } بالحجة والبرهان، ويكون داعيا لإخضاعهم بالسيف والسنان.
