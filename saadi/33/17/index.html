الآية ١٧

تيسير الكريم الرحمن — السعدي

قُلْ مَن ذَا ٱلَّذِى يَعْصِمُكُم مِّنَ ٱللَّهِ إِنْ أَرَادَ بِكُمْ سُوٓءًا أَوْ أَرَادَ بِكُمْ رَحْمَةً ۚ وَلَا يَجِدُونَ لَهُم مِّن دُونِ ٱللَّهِ وَلِيًّا وَلَا نَصِيرًا ﴿١٧﴾

ثم بين أن الأسباب كلها لا تغني عن العبد شيئًا إذا أراده اللّه بسوء، فقال: { قُلْ مَنْ ذَا الَّذِي يَعْصِمُكُمْ } أي: يمنعكم { من اللَّهِ إِنْ أَرَادَ بِكُمْ سُوءًا } أي: شرًا، { أَوْ أَرَادَ بِكُمْ رَحْمَةً } فإنه هو المعطي المانع، الضار النافع، الذي لا يأتي بالخير إلا هو، ولا يدفع السوء إلا هو.{ وَلَا يَجِدُونَ لَهُمْ مِنْ دُونِ اللَّهِ وَلِيًّا } يتولاهم، فيجلب لهم النفع { وَلَا نَصِيرًا } أي ينصرهم، فيدفع عنهم المضار.فَلْيَمْتَثِلُوا طاعة المنفرد بالأمور كلها، الذي نفذت مشيئته، ومضى قدره، ولم ينفع مع ترك ولايته ونصرته، وَلِيٌّ ولا ناصر.
