تيسير الكريم الرحمن — السعدي

ذَٰلِكَ بِأَنَّهُمْ كَانَت تَّأْتِيهِمْ رُسُلُهُم بِٱلْبَيِّنَـٰتِ فَكَفَرُوا۟ فَأَخَذَهُمُ ٱللَّهُ ۚ إِنَّهُۥ قَوِىٌّ شَدِيدُ ٱلْعِقَابِ ﴿٢٢﴾

{ إِنَّهُ قَوِيٌّ شَدِيدُ الْعِقَابِ } فلم تغن قوتهم عند قوة اللّه شيئًا، بل من أعظم الأمم قوة، قوم عاد الذين قالوا: { مَنْ أَشَدُّ مِنَّا قُوَّةً } أرسل اللّه إليهم ريحا أضعفت قواهم، ودمرتهم كل تدمير.ثم ذكر نموذجا من أحوال المكذبين بالرسل وهو فرعون وجنوده فقال:
