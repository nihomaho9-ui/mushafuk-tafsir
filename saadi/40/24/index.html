تيسير الكريم الرحمن — السعدي

إِلَىٰ فِرْعَوْنَ وَهَـٰمَـٰنَ وَقَـٰرُونَ فَقَالُوا۟ سَـٰحِرٌ كَذَّابٌ ﴿٢٤﴾

والمبعوث إليهم { فِرْعَوْنَ وَهَامَانَ } وزيره { وَقَارُونَ } الذي كان من قوم موسى، فبغى عليهم بماله، وكلهم ردوا عليه أشد الرد { فَقَالُوا سَاحِرٌ كَذَّابٌ }
