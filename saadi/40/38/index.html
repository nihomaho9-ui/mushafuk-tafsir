الآية ٣٨

تيسير الكريم الرحمن — السعدي

وَقَالَ ٱلَّذِىٓ ءَامَنَ يَـٰقَوْمِ ٱتَّبِعُونِ أَهْدِكُمْ سَبِيلَ ٱلرَّشَادِ ﴿٣٨﴾

{ وَقَالَ الَّذِي آمَنَ } معيدًا نصيحته لقومه: { يَا قَوْمِ اتَّبِعُونِ أَهْدِكُمْ سَبِيلَ الرَّشَادِ } لا كما يقول لكم فرعون، فإنه لا يهديكم إلا طريق الغي والفساد.
