الآية ٤٧

تيسير الكريم الرحمن — السعدي

وَإِذْ يَتَحَآجُّونَ فِى ٱلنَّارِ فَيَقُولُ ٱلضُّعَفَـٰٓؤُا۟ لِلَّذِينَ ٱسْتَكْبَرُوٓا۟ إِنَّا كُنَّا لَكُمْ تَبَعًا فَهَلْ أَنتُم مُّغْنُونَ عَنَّا نَصِيبًا مِّنَ ٱلنَّارِ ﴿٤٧﴾

يخبر تعالى عن تخاصم أهل النار، وعتاب بعضهم بعضًا واستغاثتهم بخزنة النار، وعدم الفائدة في ذلك فقال: { وَإِذْ يَتَحَاجُّونَ فِي النَّارِ } يحتج التابعون بإغواء المتبوعين، ويتبرأ المتبوعون من التابعين، { فَيَقُولُ الضُّعَفَاءُ } أي: الأتباع للقادة { لِلَّذِينَ اسْتَكْبَرُوا } على الحق، ودعوهم إلى ما استكبروا لأجله. { إِنَّا كُنَّا لَكُمْ تَبَعًا } أنتم أغويتمونا وأضللتمونا وزينتم لنا الشرك والشر، { فَهَلْ أَنْتُمْ مُغْنُونَ عَنَّا نَصِيبًا مِنَ النَّارِ } أي: ولو قليلاً.
