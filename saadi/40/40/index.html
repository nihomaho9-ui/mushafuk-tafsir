الآية ٤٠

تيسير الكريم الرحمن — السعدي

مَنْ عَمِلَ سَيِّئَةً فَلَا يُجْزَىٰٓ إِلَّا مِثْلَهَا ۖ وَمَنْ عَمِلَ صَـٰلِحًا مِّن ذَكَرٍ أَوْ أُنثَىٰ وَهُوَ مُؤْمِنٌ فَأُو۟لَـٰٓئِكَ يَدْخُلُونَ ٱلْجَنَّةَ يُرْزَقُونَ فِيهَا بِغَيْرِ حِسَابٍ ﴿٤٠﴾

{ مَنْ عَمِلَ سَيِّئَةً } من شرك أو فسوق أو عصيان { فَلَا يُجْزَى إِلَّا مِثْلَهَا } أي: لا يجازى إلا بما يسوؤه ويحزنه لأن جزاء السيئة السوء.{ وَمَنْ عَمِلَ صَالِحًا مِنْ ذَكَرٍ أَوْ أُنْثَى } من أعمال القلوب والجوارح، وأقوال اللسان { فَأُولَئِكَ يَدْخُلُونَ الْجَنَّةَ يُرْزَقُونَ فِيهَا بِغَيْرِ حِسَابٍ } أي: يعطون أجرهم بلا حد ولا عد، بل يعطيهم الله ما لا تبلغه أعمالهم.
