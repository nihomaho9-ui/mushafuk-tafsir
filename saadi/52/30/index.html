الطورالآية ٣٠

تيسير الكريم الرحمن — السعدي

أَمْ يَقُولُونَ شَاعِرٌ نَّتَرَبَّصُ بِهِۦ رَيْبَ ٱلْمَنُونِ ﴿٣٠﴾

وتارة { يَقُولُونَ } فيه: إنه { شَاعِرٌ } يقول الشعر، والذي جاء به شعر،والله يقول: { وَمَا عَلَّمْنَاهُ الشِّعْرَ وَمَا يَنْبَغِي لَهُ } { نَتَرَبَّصُ بِهِ رَيْبَ الْمَنُونِ } أي: ننتظر به الموت فسيبطل أمره، [ونستريح منه].
