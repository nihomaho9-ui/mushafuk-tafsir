الآية ٣١

تيسير الكريم الرحمن — السعدي

قُلْ تَرَبَّصُوا۟ فَإِنِّى مَعَكُم مِّنَ ٱلْمُتَرَبِّصِينَ ﴿٣١﴾

{ قُلْ } لهم جوابا لهذا الكلام السخيف: { تَرَبَّصُوا } أي: انتظروا بي الموت،{ فَإِنِّي مَعَكُمْ مِنَ الْمُتَرَبِّصِينَ } نتربص بكم، أن يصيبكم الله بعذاب من عنده، أو بأيدينا،
