الآية ٢٤

تيسير الكريم الرحمن — السعدي

وَيَطُوفُ عَلَيْهِمْ غِلْمَانٌ لَّهُمْ كَأَنَّهُمْ لُؤْلُؤٌ مَّكْنُونٌ ﴿٢٤﴾

{ وَيَطُوفُ عَلَيْهِمْ غِلْمَانٌ لَهُمْ } أي: خدم شباب { كَأَنَّهُمْ لُؤْلُؤٌ مَكْنُونٌ } من حسنهم وبهائهم، يدورون عليهم بالخدمة وقضاء ما يحتاجون إليه وهذا يدل على كثرة نعيمهم وسعته، وكمال راحتهم.
