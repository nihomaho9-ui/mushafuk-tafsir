الآية ٢٦

تيسير الكريم الرحمن — السعدي

قَالُوٓا۟ إِنَّا كُنَّا قَبْلُ فِىٓ أَهْلِنَا مُشْفِقِينَ ﴿٢٦﴾

{ قَالُوا } في ذكربيان الذي أوصلهم إلى ما هم فيه من الحبرة والسرور: { إِنَّا كُنَّا قَبْلُ } أي: في دار الدنيا { فِي أَهْلِنَا مُشْفِقِينَ } أي: خائفين وجلين، فتركنا من خوفه الذنوب، وأصلحنا لذلك العيوب.
