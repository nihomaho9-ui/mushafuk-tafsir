الآية ١٧٣

تيسير الكريم الرحمن — السعدي

ٱلَّذِينَ قَالَ لَهُمُ ٱلنَّاسُ إِنَّ ٱلنَّاسَ قَدْ جَمَعُوا۟ لَكُمْ فَٱخْشَوْهُمْ فَزَادَهُمْ إِيمَـٰنًا وَقَالُوا۟ حَسْبُنَا ٱللَّهُ وَنِعْمَ ٱلْوَكِيلُ ﴿١٧٣﴾

وجاءهم من جاءهم وقال لهم: { إن الناس قد جمعوا لكم } وهموا باستئصالكم، تخويفا لهم وترهيبا، فلم يزدهم ذلك إلا إيمانا بالله واتكالا عليه. { وقالوا حسبنا الله } أي: كافينا كل ما أهمنا { ونعم الوكيل } المفوض إليه تدبير عباده، والقائم بمصالحهم.
