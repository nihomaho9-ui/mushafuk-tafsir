الآية ١٦

تيسير الكريم الرحمن — السعدي

ءَأَمِنتُم مَّن فِى ٱلسَّمَآءِ أَن يَخْسِفَ بِكُمُ ٱلْأَرْضَ فَإِذَا هِىَ تَمُورُ ﴿١٦﴾

هذا تهديد ووعيد، لمن استمر في طغيانه وتعديه، وعصيانه الموجب للنكال وحلول العقوبة، فقال: { أَأَمِنْتُمْ مَنْ فِي السَّمَاءِ } وهو الله تعالى، العالي على خلقه. { أَنْ يَخْسِفَ بِكُمُ الْأَرْضَ فَإِذَا هِيَ تَمُورُ } بكم وتضطرب، حتى تتلفكم وتهلككم
