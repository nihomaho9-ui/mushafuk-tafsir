الآية ١٠٧

تيسير الكريم الرحمن — السعدي

فَإِنْ عُثِرَ عَلَىٰٓ أَنَّهُمَا ٱسْتَحَقَّآ إِثْمًا فَـَٔاخَرَانِ يَقُومَانِ مَقَامَهُمَا مِنَ ٱلَّذِينَ ٱسْتَحَقَّ عَلَيْهِمُ ٱلْأَوْلَيَـٰنِ فَيُقْسِمَانِ بِٱللَّهِ لَشَهَـٰدَتُنَآ أَحَقُّ مِن شَهَـٰدَتِهِمَا وَمَا ٱعْتَدَيْنَآ إِنَّآ إِذًا لَّمِنَ ٱلظَّـٰلِمِينَ ﴿١٠٧﴾

{ فَإِنْ عُثِرَ عَلَى أَنَّهُمَا } أي: الشاهدين { اسْتَحَقَّا إِثْمًا } بأن وجد من القرائن ما يدل على كذبهما وأنهما خانا { فآخران يقومان مقامهما من الذين استحق عليهم الأوليان } أي: فليقم رجلان من أولياء الميت، وليكونا من أقرب الأولياء إليه. { فَيُقْسِمَانِ بِاللَّهِ لَشَهَادَتُنَا أَحَقُّ مِنْ شَهَادَتِهِمَا } أي: أنهما كذبا، وغيرا وخانا. { وَمَا اعْتَدَيْنَا إِنَّا إِذًا لَمِنَ الظَّالِمِينَ } أي: إن ظلمنا واعتدينا، وشهدنا بغير الحق.
