الآية ٢٩

تيسير الكريم الرحمن — السعدي

وَقَالُوٓا۟ إِنْ هِىَ إِلَّا حَيَاتُنَا ٱلدُّنْيَا وَمَا نَحْنُ بِمَبْعُوثِينَ ﴿٢٩﴾

} { وَقَالُوا } منكرين للبعث { إِنْ هِيَ إِلَّا حَيَاتُنَا الدُّنْيَا } أي: ما حقيقة الحال والأمر وما المقصود من إيجادنا، إلا الحياة الدنيا وحدها. { وَمَا نَحْنُ بِمَبْعُوثِينَ }
