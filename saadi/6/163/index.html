الآية ١٦٣

تيسير الكريم الرحمن — السعدي

لَا شَرِيكَ لَهُۥ ۖ وَبِذَٰلِكَ أُمِرْتُ وَأَنَا۠ أَوَّلُ ٱلْمُسْلِمِينَ ﴿١٦٣﴾

{ لَا شَرِيكَ لَهُ } في العبادة، كما أنه ليس له شريك في الملك والتدبير، وليس هذا الإخلاص لله ابتداعا مني، وبدعا أتيته من تلقاء نفسي، بل { بِذَلِكَ أُمِرْتُ } أمرا حتما، لا أخرج من التبعة إلا بامتثاله { وَأَنَا أَوَّلُ الْمُسْلِمِينَ } من هذه الأمة.
