تيسير الكريم الرحمن — السعدي

قُلْ إِنِّى نُهِيتُ أَنْ أَعْبُدَ ٱلَّذِينَ تَدْعُونَ مِن دُونِ ٱللَّهِ ۚ قُل لَّآ أَتَّبِعُ أَهْوَآءَكُمْ ۙ قَدْ ضَلَلْتُ إِذًا وَمَآ أَنَا۠ مِنَ ٱلْمُهْتَدِينَ ﴿٥٦﴾

يقول تعالى لنبيه صلى الله عليه وسلم: { قُلْ } لهؤلاء المشركين الذين يدعون مع الله آلهة أخرى: { إِنِّي نُهِيتُ أَنْ أَعْبُدَ الَّذِينَ تَدْعُونَ مِنْ دُونِ اللَّهِ } من الأنداد والأوثان، التي لا تملك نفعا ولا ضرا، ولا موتا ولا حياة ولا نشورا، فإن هذا باطل، وليس لكم فيه حجة بل ولا شبهة، ولا اتباع الهوى الذي اتباعه أعظم الضلال، ولهذا قال { قُلْ لَا أَتَّبِعُ أَهْوَاءَكُمْ قَدْ ضَلَلْتُ إِذًا } أي: إن اتبعت أهواءكم { وَمَا أَنَا مِنَ الْمُهْتَدِينَ } بوجه من الوجوه.
