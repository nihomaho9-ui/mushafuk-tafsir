تيسير الكريم الرحمن — السعدي

وَمَآ أَدْرَىٰكَ مَا سِجِّينٌ ﴿٨﴾

كِتَـٰبٌ مَّرْقُومٌ ﴿٩﴾

الآيات ٨–٩{ وَمَا أَدْرَاكَ مَا سِجِّينٌ كِتَابٌ مَرْقُومٌ } أي: كتاب مذكور فيه أعمالهم الخبيثة، والسجين: المحل الضيق الضنك، و { سجين } ضد { عليين } الذي هو محل كتاب الأبرار، كما سيأتي.وقد قيل: إن { سجين } هو أسفل الأرض السابعة، مأوى الفجار ومستقرهم في معادهم.
