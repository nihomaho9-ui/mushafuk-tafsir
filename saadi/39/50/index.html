الآية ٥٠

تيسير الكريم الرحمن — السعدي

قَدْ قَالَهَا ٱلَّذِينَ مِن قَبْلِهِمْ فَمَآ أَغْنَىٰ عَنْهُم مَّا كَانُوا۟ يَكْسِبُونَ ﴿٥٠﴾

قال تعالى: { قَدْ قَالَهَا الَّذِينَ مِنْ قَبْلِهِمْ } أي: قولهم { إِنَّمَا أُوتِيتُهُ عَلَى عِلْمٍ } فما زالت متوارثة عند المكذبين، لا يقرون بنعمة ربهم، ولا يرون له حقا،.فلم يزل دأبهم حتى أهلكوا، ولم يغن { عَنْهُمْ مَا كَانُوا يَكْسِبُونَ } حين جاءهم العذاب.
