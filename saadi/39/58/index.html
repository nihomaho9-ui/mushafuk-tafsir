تيسير الكريم الرحمن — السعدي

أَوْ تَقُولَ حِينَ تَرَى ٱلْعَذَابَ لَوْ أَنَّ لِى كَرَّةً فَأَكُونَ مِنَ ٱلْمُحْسِنِينَ ﴿٥٨﴾

{ أَوْ تَقُولَ حِينَ تَرَى الْعَذَابَ } وتجزم بوروده { لَوْ أَنَّ لِي كَرَّةً } أي: رجعة إلى الدنيا لكنت { مِنَ الْمُحْسِنِينَ } قال تعالى: إن ذلك غير ممكن ولا مفيد، وإن هذه أماني باطلة لا حقيقة لها، إذ لا يتجدد للعبد لَوْ رُدَّ، بيان بعد البيان الأول.
