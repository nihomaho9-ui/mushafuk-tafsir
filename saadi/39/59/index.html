الآية ٥٩

تيسير الكريم الرحمن — السعدي

بَلَىٰ قَدْ جَآءَتْكَ ءَايَـٰتِى فَكَذَّبْتَ بِهَا وَٱسْتَكْبَرْتَ وَكُنتَ مِنَ ٱلْكَـٰفِرِينَ ﴿٥٩﴾

{ بَلَى قَدْ جَاءَتْكَ آيَاتِي } الدالة دلالة لا يمترى فيها. على الحق { فَكَذَّبْتَ بِهَا وَاسْتَكْبَرْتَ } عن اتباعها { وَكُنْتَ مِنَ الْكَافِرِينَ } فسؤال الرد إلى الدنيا، نوع عبث، { وَلَوْ رُدُّوا لَعَادُوا لِمَا نُهُوا عَنْهُ وَإِنَّهُمْ لَكَاذِبُونَ } .
