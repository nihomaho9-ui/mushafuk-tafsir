الآية ١٥

تيسير الكريم الرحمن — السعدي

فَٱعْبُدُوا۟ مَا شِئْتُم مِّن دُونِهِۦ ۗ قُلْ إِنَّ ٱلْخَـٰسِرِينَ ٱلَّذِينَ خَسِرُوٓا۟ أَنفُسَهُمْ وَأَهْلِيهِمْ يَوْمَ ٱلْقِيَـٰمَةِ ۗ أَلَا ذَٰلِكَ هُوَ ٱلْخُسْرَانُ ٱلْمُبِينُ ﴿١٥﴾

{ قُلِ اللَّهَ أَعْبُدُ مُخْلِصًا لَهُ دِينِي فَاعْبُدُوا مَا شِئْتُمْ مِنْ دُونِهِ } كما قال تعالى: { قُلْ يَا أَيُّهَا الْكَافِرُونَ* لَا أَعْبُدُ مَا تَعْبُدُونَ* وَلَا أَنْتُمْ عَابِدُونَ مَا أَعْبُدُ* وَلَا أَنَا عَابِدٌ مَا عَبَدْتُمْ* وَلَا أَنْتُمْ عَابِدُونَ مَا أَعْبُدُ* لَكُمْ دِينُكُمْ وَلِيَ دِينِ } { قُلْ إِنَّ الْخَاسِرِينَ } حقيقة هم { الَّذِينَ خَسِرُوا أَنْفُسَهُمْ } حيث حرموها الثواب، واستحقت بسببهم وخيم العقاب { وَأَهْلِيهِمْ يَوْمَ الْقِيَامَةِ } أي: فرق بينهم وبينهم، واشتد عليهم الحزن، وعظم الخسران. { أَلَا ذَلِكَ هُوَ الْخُسْرَانُ الْمُبِينُ } الذي ليس مثله خسران، وهو خسران مستمر، لا ربح بعده، بل ولا سلامة.
