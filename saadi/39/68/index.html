الآية ٦٨

تيسير الكريم الرحمن — السعدي

وَنُفِخَ فِى ٱلصُّورِ فَصَعِقَ مَن فِى ٱلسَّمَـٰوَٰتِ وَمَن فِى ٱلْأَرْضِ إِلَّا مَن شَآءَ ٱللَّهُ ۖ ثُمَّ نُفِخَ فِيهِ أُخْرَىٰ فَإِذَا هُمْ قِيَامٌ يَنظُرُونَ ﴿٦٨﴾

لما خوفهم تعالى من عظمته، خوفهم بأحوال يوم القيامة، ورغَّبهم ورهَّبهم فقال: { وَنُفِخَ فِي الصُّورِ } وهو قرن عظيم، لا يعلم عظمته إلا خالقه، ومن أطلعه اللّه على علمه من خلقه،. فينفخ فيه إسرافيل عليه السلام،. أحد الملائكة المقربين، وأحد حملة عرش الرحمن.{ فَصَعِقَ } أي: غشي أو مات، على اختلاف القولين: { مَنْ فِي السَّمَاوَاتِ وَمَنْ فِي الْأَرْضِ } أي: كلهم، لما سمعوا نفخة الصور أزعجتهم من شدتها وعظمها، وما يعلمون أنها مقدمة له. { إِلَّا مَنْ شَاءَ اللَّهُ } ممن ثبته اللّه عند النفخة، فلم يصعق، كالشهداء أو بعضهم، وغيرهم. وهذه النفخة الأولى، نفخة الصعق، ونفخة الفزع.{ ثُمَّ نُفِخَ فِيهِ } النفخة الثانية نفخة البعث { فَإِذَا هُمْ قِيَامٌ ينظرون } أي: قد قاموا من قبورهم لبعثهم وحسابهم، قد تمت منهم الخلقة الجسدية والأرواح، وشخصت أبصارهم { يَنْظُرُونَ } ماذا يفعل اللّه بهم.
