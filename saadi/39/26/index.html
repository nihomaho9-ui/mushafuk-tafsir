تيسير الكريم الرحمن — السعدي

فَأَذَاقَهُمُ ٱللَّهُ ٱلْخِزْىَ فِى ٱلْحَيَوٰةِ ٱلدُّنْيَا ۖ وَلَعَذَابُ ٱلْـَٔاخِرَةِ أَكْبَرُ ۚ لَوْ كَانُوا۟ يَعْلَمُونَ ﴿٢٦﴾

{ فَأَذَاقَهُمُ اللَّهُ } بذلك العذاب { الْخِزْيَ فِي الْحَيَاةِ الدُّنْيَا } فافتضحوا عند اللّه وعند خلقه { وَلَعَذَابُ الْآخِرَةِ أَكْبَرُ لَوْ كَانُوا يَعْلَمُونَ } فليحذر هؤلاء من المقام على التكذيب، فيصيبهم ما أصاب أولئك من التعذيب.
