الآية ٨٠

تيسير الكريم الرحمن — السعدي

فَلَمَّا ٱسْتَيْـَٔسُوا۟ مِنْهُ خَلَصُوا۟ نَجِيًّا ۖ قَالَ كَبِيرُهُمْ أَلَمْ تَعْلَمُوٓا۟ أَنَّ أَبَاكُمْ قَدْ أَخَذَ عَلَيْكُم مَّوْثِقًا مِّنَ ٱللَّهِ وَمِن قَبْلُ مَا فَرَّطتُمْ فِى يُوسُفَ ۖ فَلَنْ أَبْرَحَ ٱلْأَرْضَ حَتَّىٰ يَأْذَنَ لِىٓ أَبِىٓ أَوْ يَحْكُمَ ٱللَّهُ لِى ۖ وَهُوَ خَيْرُ ٱلْحَـٰكِمِينَ ﴿٨٠﴾

أي: فلما استيأس إخوة يوسف من يوسف أن يسمح لهم بأخيهم { خَلَصُوا نَجِيًّا } أي: اجتمعوا وحدهم، ليس معهم غيرهم، وجعلوا يتناجون فيما بينهم، فـ { قَالَ كَبِيرُهُمْ أَلَمْ تَعْلَمُوا أَنَّ أَبَاكُمْ قَدْ أَخَذَ عَلَيْكُمْ مَوْثِقًا مِنَ اللَّهِ } في حفظه، وأنكم تأتون به إلا أن يحاط بكم { وَمِنْ قَبْلُ مَا فَرَّطْتُمْ فِي يُوسُفَ } ، فاجتمع عليكم الأمران، تفريطكم في يوسف السابق، وعدم إتيانكم بأخيه باللاحق، فليس لي وجه أواجه به أبي. { فَلَنْ أَبْرَحَ الْأَرْضَ } أي: سأقيم في هذه الأرض ولا أزال بها { حَتَّى يَأْذَنَ لِي أَبِي أَوْ يَحْكُمَ اللَّهُ لِي } أي: يقدر لي المجيء وحدي، أو مع أخي { وَهُوَ خَيْرُ الْحَاكِمِينَ }
