الآية ٣٤

تيسير الكريم الرحمن — السعدي

فَٱسْتَجَابَ لَهُۥ رَبُّهُۥ فَصَرَفَ عَنْهُ كَيْدَهُنَّ ۚ إِنَّهُۥ هُوَ ٱلسَّمِيعُ ٱلْعَلِيمُ ﴿٣٤﴾

{ فَاسْتَجَابَ لَهُ رَبُّهُ } حين دعاه { فَصَرَفَ عَنْهُ كَيْدَهُنَّ } فلم تزل تراوده وتستعين عليه بما تقدر عليه من الوسائل، حتى أيسها، وصرف الله عنه كيدها، { إِنَّهُ هُوَ السَّمِيعُ } لدعاء الداعي { الْعَلِيمُ } بنيته الصالحة، وبنيته الضعيفة المقتضية لإمداده بمعونته ولطفه. فهذا ما نجى الله به يوسف من هذه الفتنة الملمة والمحنة الشديدة
