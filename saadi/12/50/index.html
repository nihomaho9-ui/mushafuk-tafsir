يوسفالآية ٥٠

تيسير الكريم الرحمن — السعدي

وَقَالَ ٱلْمَلِكُ ٱئْتُونِى بِهِۦ ۖ فَلَمَّا جَآءَهُ ٱلرَّسُولُ قَالَ ٱرْجِعْ إِلَىٰ رَبِّكَ فَسْـَٔلْهُ مَا بَالُ ٱلنِّسْوَةِ ٱلَّـٰتِى قَطَّعْنَ أَيْدِيَهُنَّ ۚ إِنَّ رَبِّى بِكَيْدِهِنَّ عَلِيمٌ ﴿٥٠﴾

يقول تعالى: { وَقَالَ الْمَلِكُ } لمن عنده { ائْتُونِي بِهِ } أي: بيوسف عليه السلام، بأن يخرجوه من السجن ويحضروه إليه، فلما جاء يوسف الرسول وأمره بالحضور عند الملك، امتنع عن المبادرة إلى الخروج، حتى تتبين براءته التامة، وهذا من صبره وعقله ورأيه التام. فـ { قَالَ } للرسول: { ارْجِعْ إِلَى رَبِّكَ } يعني به الملك. { فَاسْأَلْهُ مَا بَالُ النِّسْوَةِ اللَّاتِي قَطَّعْنَ أَيْدِيَهُنَّ } أي: اسأله ما شأنهن وقصتهن، فإن أمرهن ظاهر متضح { إِنَّ رَبِّي بِكَيْدِهِنَّ عَلِيمٌ }.
