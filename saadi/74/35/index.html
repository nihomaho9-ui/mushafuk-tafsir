المدثر

الآيات ٣٥–٣٦

تيسير الكريم الرحمن — السعدي

إِنَّهَا لَإِحْدَى ٱلْكُبَرِ ﴿٣٥﴾

نَذِيرًا لِّلْبَشَرِ ﴿٣٦﴾

الآيات ٣٥–٣٦والمقسم عليه قوله: { إِنَّهَا } أي النار { لَإِحْدَى الْكُبَرِ } أي: لإحدى العظائم الطامة والأمور الهامة، فإذا أعلمناكم بها، وكنتم على بصيرة من أمرها.
