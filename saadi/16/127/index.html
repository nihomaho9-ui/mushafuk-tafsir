النحلالآية ١٢٧

تيسير الكريم الرحمن — السعدي

وَٱصْبِرْ وَمَا صَبْرُكَ إِلَّا بِٱللَّهِ ۚ وَلَا تَحْزَنْ عَلَيْهِمْ وَلَا تَكُ فِى ضَيْقٍ مِّمَّا يَمْكُرُونَ ﴿١٢٧﴾

ثم أمر رسوله بالصبر على دعوة الخلق إلى الله والاستعانة بالله على ذلك وعدم الاتكال على النفس فقال: { وَاصْبِرْ وَمَا صَبْرُكَ إِلَّا بِاللَّهِ } هو الذي يعينك عليه ويثبتك. { وَلَا تَحْزَنْ عَلَيْهِمْ } إذا دعوتهم فلم تر منهم قبولا لدعوتك، فإن الحزن لا يجدي عليك شيئا. { وَلَا تَكُ فِي ضَيْقٍ } أي: شدة وحرج { مِمَّا يَمْكُرُونَ } فإن مكرهم عائد إليهم وأنت من المتقين المحسنين.
