الآية ٨٢

تيسير الكريم الرحمن — السعدي

فَإِن تَوَلَّوْا۟ فَإِنَّمَا عَلَيْكَ ٱلْبَلَـٰغُ ٱلْمُبِينُ ﴿٨٢﴾

{ فَإِنْ تَوَلَّوْا } عن الله وعن طاعته بعد ما ذُكِّروا بنعمه وآياته، { فَإِنَّمَا عَلَيْكَ الْبَلَاغُ الْمُبِينُ } أي: ليس عليك من هدايتهم وتوفيقهم شيء بل أنت مطالب بالوعظ والتذكير والإنذار والتحذير.
