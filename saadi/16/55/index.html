النحلالآية ٥٥

تيسير الكريم الرحمن — السعدي

لِيَكْفُرُوا۟ بِمَآ ءَاتَيْنَـٰهُمْ ۚ فَتَمَتَّعُوا۟ ۖ فَسَوْفَ تَعْلَمُونَ ﴿٥٥﴾

{ ِليَكْفُرُوا بِمَا آتَيْنَاهُمْ } أي: أعطيناهم حيث نجيناهم من الشدة، وخلصناهم من المشقة، { فَتَمَتَّعُوا } في دنياكم قليلا { فَسَوْفَ تَعْلَمُونَ } عاقبة كفركم.
