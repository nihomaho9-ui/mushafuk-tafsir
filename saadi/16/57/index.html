الآية ٥٧

تيسير الكريم الرحمن — السعدي

وَيَجْعَلُونَ لِلَّهِ ٱلْبَنَـٰتِ سُبْحَـٰنَهُۥ ۙ وَلَهُم مَّا يَشْتَهُونَ ﴿٥٧﴾

{ وَيَجْعَلُونَ لِلَّهِ الْبَنَاتِ } حيث قالوا عن الملائكة العباد المقربين: إنهم بنات الله { وَلَهُمْ مَا يَشْتَهُونَ } أي: لأنفسهم الذكور حتى إنهم يكرهون البنات كراهة شديدة
