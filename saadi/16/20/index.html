النحلالآية ٢٠

تيسير الكريم الرحمن — السعدي

وَٱلَّذِينَ يَدْعُونَ مِن دُونِ ٱللَّهِ لَا يَخْلُقُونَ شَيْـًٔا وَهُمْ يُخْلَقُونَ ﴿٢٠﴾

تفسير الآيتين 19 و20 :ـ وكما أن رحمته واسعة وجوده عميم ومغفرته شاملة للعباد فعلمه محيط بهم، { يَعْلَمُ مَا تُسِرُّونَ وَمَا تُعْلِنُونَ } بخلاف من عبد من دونه، فإنهم { لَا يَخْلُقُونَ شَيْئًا } قليلا ولا كثيرا { وَهُمْ يُخْلَقُونَ } فكيف يخلقون شيئا مع افتقارهم في إيجادهم إلى الله تعالى؟\"
