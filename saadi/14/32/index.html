تيسير الكريم الرحمن — السعدي

ٱللَّهُ ٱلَّذِى خَلَقَ ٱلسَّمَـٰوَٰتِ وَٱلْأَرْضَ وَأَنزَلَ مِنَ ٱلسَّمَآءِ مَآءً فَأَخْرَجَ بِهِۦ مِنَ ٱلثَّمَرَٰتِ رِزْقًا لَّكُمْ ۖ وَسَخَّرَ لَكُمُ ٱلْفُلْكَ لِتَجْرِىَ فِى ٱلْبَحْرِ بِأَمْرِهِۦ ۖ وَسَخَّرَ لَكُمُ ٱلْأَنْهَـٰرَ ﴿٣٢﴾

يخبر تعالى: أنه وحده { الَّذِي خَلَقَ السَّمَاوَاتِ وَالْأَرْضَ } على اتساعهما وعظمهما، { وَأَنْزَلَ مِنَ السَّمَاءِ مَاءً } وهو: المطر الذي ينزله الله من السحاب، { فَأَخْرَجَ } بذلك الماء { مِنَ الثَّمَرَاتِ } المختلفة الأنواع { رِزْقًا لَكُمْ } ورزقا لأنعامكم { وَسَخَّرَ لَكُمُ الْفُلْكَ } أي: السفن والمراكب. { لِتَجْرِيَ فِي الْبَحْرِ بِأَمْرِهِ } فهو الذي يسر لكم صنعتها وأقدركم عليها، وحفظها على تيار الماء لتحملكم، وتحمل تجاراتكم، وأمتعتكم إلى بلد تقصدونه. { وَسَخَّرَ لَكُمُ الْأَنْهَارَ } لتسقي حروثكم وأشجاركم وتشربوا منها.
