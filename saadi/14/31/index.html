الآية ٣١

تيسير الكريم الرحمن — السعدي

قُل لِّعِبَادِىَ ٱلَّذِينَ ءَامَنُوا۟ يُقِيمُوا۟ ٱلصَّلَوٰةَ وَيُنفِقُوا۟ مِمَّا رَزَقْنَـٰهُمْ سِرًّا وَعَلَانِيَةً مِّن قَبْلِ أَن يَأْتِىَ يَوْمٌ لَّا بَيْعٌ فِيهِ وَلَا خِلَـٰلٌ ﴿٣١﴾

أي: قل لعبادي المؤمنين آمرا لهم بما فيه غاية صلاحهم وأن ينتهزوا الفرصة، قبل أن لا يمكنهم ذلك: { يُقِيمُوا الصَّلَاة } ظاهرا وباطنا { وَيُنْفِقُوا مِمَّا رَزَقْنَاهُمْ } أي: من النعم التي أنعمنا بها عليهم قليلا أو كثيرا { سِرًّا وَعَلَانِيَةً } وهذا يشمل النفقة الواجبة كالزكاة ونفقة من تجب [عليه] نفقته، والمستحبة كالصدقات ونحوها. { مِنْ قَبْلِ أَنْ يَأْتِيَ يَوْمٌ لَا بَيْعٌ فِيهِ وَلَا خِلَالٌ } أي: لا ينفع فيه شيء ولا سبيل إلى استدراك ما فات لا بمعاوضة بيع وشراء ولا بهبة خليل وصديق، فكل امرئ له شأن يغنيه، فليقدم العبد لنفسه، ولينظر ما قدمه لغد، وليتفقد أعماله، ويحاسب نفسه، قبل الحساب الأكبر.
