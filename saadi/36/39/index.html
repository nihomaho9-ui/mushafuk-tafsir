الآية ٣٩

تيسير الكريم الرحمن — السعدي

وَٱلْقَمَرَ قَدَّرْنَـٰهُ مَنَازِلَ حَتَّىٰ عَادَ كَٱلْعُرْجُونِ ٱلْقَدِيمِ ﴿٣٩﴾

{ وَالْقَمَرَ قَدَّرْنَاهُ مَنَازِلَ } ينزل بها، كل ليلة ينزل منها واحدة، { حَتَّى } يصغر جدا، فيعود { كَالْعُرْجُونِ الْقَدِيمِ } أي: عرجون النخلة، الذي من قدمه نش وصغر حجمه وانحنى، ثم بعد ذلك، ما زال يزيد شيئا فشيئا، حتى يتم [نوره] ويتسق ضياؤه.
