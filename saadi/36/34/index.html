يسالآية ٣٤

تيسير الكريم الرحمن — السعدي

وَجَعَلْنَا فِيهَا جَنَّـٰتٍ مِّن نَّخِيلٍ وَأَعْنَـٰبٍ وَفَجَّرْنَا فِيهَا مِنَ ٱلْعُيُونِ ﴿٣٤﴾

{ وَجَعَلْنَا فِيهَا } أي: في تلك الأرض الميتة { جَنَّاتٍ } أي: بساتين، فيها أشجار كثيرة، وخصوصا النخيل والأعناب، اللذان هما أشرف الأشجار، { وَفَجَّرْنَا فِيهَا } أي: في الأرض { مِنَ الْعُيُونِ }
