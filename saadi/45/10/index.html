الآية ١٠

تيسير الكريم الرحمن — السعدي

مِّن وَرَآئِهِمْ جَهَنَّمُ ۖ وَلَا يُغْنِى عَنْهُم مَّا كَسَبُوا۟ شَيْـًٔا وَلَا مَا ٱتَّخَذُوا۟ مِن دُونِ ٱللَّهِ أَوْلِيَآءَ ۖ وَلَهُمْ عَذَابٌ عَظِيمٌ ﴿١٠﴾

وأخبر أن له عذابا أليما وأن { مِنْ وَرَائِهِمْ جَهَنَّمُ } تكفي في عقوبتهم البليغة. وأنه { لا يُغْنِي عَنْهُمْ مَا كَسَبُوا } من الأموال { وَلَا مَا اتَّخَذُوا مِنْ دُونِ اللَّهِ أَوْلِيَاءَ } يستنصرون بهم فخذلوهم أحوج ما كانوا إليهم لو نفعوا.
