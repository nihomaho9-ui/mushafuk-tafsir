الآية ٤٦

تيسير الكريم الرحمن — السعدي

بَلِ ٱلسَّاعَةُ مَوْعِدُهُمْ وَٱلسَّاعَةُ أَدْهَىٰ وَأَمَرُّ ﴿٤٦﴾

ومع ذلك، فلهم موعد يجمع به أولهم وآخرهم، ومن أصيب في الدنيا منهم، ومن متع بلذاته، ولهذا قال: { بَلِ السَّاعَةُ مَوْعِدُهُمْ } الذي يحازون به، ويؤخذ منهم الحق بالقسط، { وَالسَّاعَةُ أَدْهَى وَأَمَرُّ } أي: أعظم وأشق، وأكبر من كل ما يتوهم، أو يدور بالبال
