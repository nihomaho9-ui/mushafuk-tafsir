الآية ٧١

تيسير الكريم الرحمن — السعدي

قَالَ إِنَّهُۥ يَقُولُ إِنَّهَا بَقَرَةٌ لَّا ذَلُولٌ تُثِيرُ ٱلْأَرْضَ وَلَا تَسْقِى ٱلْحَرْثَ مُسَلَّمَةٌ لَّا شِيَةَ فِيهَا ۚ قَالُوا۟ ٱلْـَٔـٰنَ جِئْتَ بِٱلْحَقِّ ۚ فَذَبَحُوهَا وَمَا كَادُوا۟ يَفْعَلُونَ ﴿٧١﴾

{ قَالَ إِنَّهُ يَقُولُ إِنَّهَا بَقَرَةٌ لَا ذَلُولٌ } أي: مذللة بالعمل، { تُثِيرُ الْأَرْضَ } بالحراثة { وَلَا تَسْقِي الْحَرْثَ } أي: ليست بساقية، { مُسَلَّمَةٌ } من العيوب أو من العمل { لَا شِيَةَ فِيهَا } أي: لا لون فيها غير لونها الموصوف المتقدم. { قَالُوا الْآنَ جِئْتَ بِالْحَقِّ } أي: بالبيان الواضح، وهذا من جهلهم, وإلا فقد جاءهم بالحق أول مرة، فلو أنهم اعترضوا أي: بقرة لحصل المقصود, ولكنهم شددوا بكثرة الأسئلة فشدد الله عليهم, ولو لم يقولوا \" إن شاء الله \" لم يهتدوا أيضا إليها، { فَذَبَحُوهَا } أي: البقرة التي وصفت بتلك الصفات، { وَمَا كَادُوا يَفْعَلُونَ } بسبب التعنت الذي جرى منهم.
