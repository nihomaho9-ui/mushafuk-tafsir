الآية ٢٥٠

تيسير الكريم الرحمن — السعدي

وَلَمَّا بَرَزُوا۟ لِجَالُوتَ وَجُنُودِهِۦ قَالُوا۟ رَبَّنَآ أَفْرِغْ عَلَيْنَا صَبْرًا وَثَبِّتْ أَقْدَامَنَا وَٱنصُرْنَا عَلَى ٱلْقَوْمِ ٱلْكَـٰفِرِينَ ﴿٢٥٠﴾

ولهذا لما برزوا لجالوت وجنوده { قالوا } جميعهم { ربنا أفرغ علينا صبرا } أي: قو قلوبنا، وأوزعنا الصبر، وثبت أقدامنا عن التزلزل والفرار، وانصرنا على القوم الكافرين.
