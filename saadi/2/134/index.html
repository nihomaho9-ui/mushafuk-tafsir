الآية ١٣٤

تيسير الكريم الرحمن — السعدي

تِلْكَ أُمَّةٌ قَدْ خَلَتْ ۖ لَهَا مَا كَسَبَتْ وَلَكُم مَّا كَسَبْتُمْ ۖ وَلَا تُسْـَٔلُونَ عَمَّا كَانُوا۟ يَعْمَلُونَ ﴿١٣٤﴾

ثم قال تعالى: { تِلْكَ أُمَّةٌ قَدْ خَلَتْ } أي: مضت { لَهَا مَا كَسَبَتْ وَلَكُمْ مَا كَسَبْتُمْ } أي: كُلٌّ له عمله, وكل سُيجَازى بما فعله, لا يؤخذ أحد بذنب أحد ولا ينفع أحدا إلا إيمانه وتقواه فاشتغالكم بهم وادعاؤكم, أنكم على ملتهم, والرضا بمجرد القول, أمر فارغ لا حقيقة له، بل الواجب عليكم, أن تنظروا حالتكم التي أنتم عليها, هل تصلح للنجاة أم لا؟
