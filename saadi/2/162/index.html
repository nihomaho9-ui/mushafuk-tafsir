الآية ١٦٢

تيسير الكريم الرحمن — السعدي

خَـٰلِدِينَ فِيهَا ۖ لَا يُخَفَّفُ عَنْهُمُ ٱلْعَذَابُ وَلَا هُمْ يُنظَرُونَ ﴿١٦٢﴾

خَالِدِينَ فِيهَا } أي: في اللعنة, أو في العذاب وهما متلازمان { لَا يُخَفَّفُ عَنْهُمُ الْعَذَابُ } بل عذابهم دائم شديد مستمر { وَلَا هُمْ يُنْظَرُونَ } أي: يمهلون, لأن وقت الإمهال وهو الدنيا قد مضى, ولم يبق لهم عذر فيعتذرون.
