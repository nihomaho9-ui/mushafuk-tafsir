تيسير الكريم الرحمن — السعدي

مَّا يَوَدُّ ٱلَّذِينَ كَفَرُوا۟ مِنْ أَهْلِ ٱلْكِتَـٰبِ وَلَا ٱلْمُشْرِكِينَ أَن يُنَزَّلَ عَلَيْكُم مِّنْ خَيْرٍ مِّن رَّبِّكُمْ ۗ وَٱللَّهُ يَخْتَصُّ بِرَحْمَتِهِۦ مَن يَشَآءُ ۚ وَٱللَّهُ ذُو ٱلْفَضْلِ ٱلْعَظِيمِ ﴿١٠٥﴾

أخبر عن عداوة اليهود والمشركين للمؤمنين, أنهم ما يودون { أَنْ يُنَزَّلَ عَلَيْكُمْ مِنْ خَيْرٍ } أي: لا قليلا ولا كثيرا { مِنْ رَبِّكُمْ } حسدا منهم, وبغضا لكم أن يختصكم بفضله فإنه { ذُو الْفَضْلِ الْعَظِيمِ } ومن فضله عليكم, إنزال الكتاب على رسولكم, ليزكيكم ويعلمكم الكتاب والحكمة, ويعلمكم ما لم تكونوا تعلمون, فله الحمد والمنة.
