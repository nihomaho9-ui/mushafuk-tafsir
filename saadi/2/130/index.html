الآية ١٣٠

تيسير الكريم الرحمن — السعدي

وَمَن يَرْغَبُ عَن مِّلَّةِ إِبْرَٰهِـۧمَ إِلَّا مَن سَفِهَ نَفْسَهُۥ ۚ وَلَقَدِ ٱصْطَفَيْنَـٰهُ فِى ٱلدُّنْيَا ۖ وَإِنَّهُۥ فِى ٱلْـَٔاخِرَةِ لَمِنَ ٱلصَّـٰلِحِينَ ﴿١٣٠﴾

أي: ما يرغب { عَنْ مِلَّةِ إِبْرَاهِيمَ } بعد ما عرف من فضله { إِلَّا مَنْ سَفِهَ نَفْسَهُ } أي: جهلها وامتهنها, ورضي لها بالدُّون, وباعها بصفقة المغبون، كما أنه لا أرشد وأكمل, ممن رغب في ملة إبراهيم، ثم أخبر عن حالته في الدنيا والآخرة فقال: { وَلَقَدِ اصْطَفَيْنَاهُ فِي الدُّنْيَا } أي: اخترناه ووفقناه للأعمال, التي صار بها من المصطفين الأخيار. { وَإِنَّهُ فِي الْآخِرَةِ لَمِنَ الصَّالِحِينَ } الذين لهم أعلى الدرجات.
