الآية ٥٥

تيسير الكريم الرحمن — السعدي

وَإِذْ قُلْتُمْ يَـٰمُوسَىٰ لَن نُّؤْمِنَ لَكَ حَتَّىٰ نَرَى ٱللَّهَ جَهْرَةً فَأَخَذَتْكُمُ ٱلصَّـٰعِقَةُ وَأَنتُمْ تَنظُرُونَ ﴿٥٥﴾

{ وَإِذْ قُلْتُمْ يَا مُوسَى لَنْ نُؤْمِنَ لَكَ حَتَّى نَرَى اللَّهَ جَهْرَةً } وهذا غاية الظلم والجراءة على الله وعلى رسوله، { فَأَخَذَتْكُمُ الصَّاعِقَةُ } إما الموت أو الغشية العظيمة، { وَأَنْتُمْ تَنْظُرُونَ } وقوع ذلك, كل ينظر إلى صاحبه.
