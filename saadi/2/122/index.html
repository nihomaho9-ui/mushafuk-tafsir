الآية ١٢٢

تيسير الكريم الرحمن — السعدي

يَـٰبَنِىٓ إِسْرَٰٓءِيلَ ٱذْكُرُوا۟ نِعْمَتِىَ ٱلَّتِىٓ أَنْعَمْتُ عَلَيْكُمْ وَأَنِّى فَضَّلْتُكُمْ عَلَى ٱلْعَـٰلَمِينَ ﴿١٢٢﴾

يُخبِرُ تعالى أنَّ الذين آتاهم الكتاب, ومنَّ عليهم به منةً مطلقةً, أنهم { يَتْلُونَهُ حَقَّ تِلَاوَتِهِ } أي: يتبعونه حق اتباعه, والتلاوة: الاتباع، فيحلون حلاله, ويحرمون حرامه, ويعملون بمحكمه, ويؤمنون بمتشابهه، وهؤلاء هم السعداء من أهل الكتاب, الذين عرفوا نعمة الله وشكروها, وآمنوا بكل الرسل, ولم يفرقوا بين أحد منهم. فهؤلاء, هم المؤمنون حقا, لا من قال منهم: { نؤمن بما أنزل علينا ويكفرون بما وراءه } ولهذا توعدهم بقوله { وَمَنْ يَكْفُرْ بِهِ فَأُولَئِكَ هُمُ الْخَاسِرُونَ } وقد تقدم تفسير الآية التي بعدها.
