الآية ٣٣

تيسير الكريم الرحمن — السعدي

قَالَ يَـٰٓـَٔادَمُ أَنۢبِئْهُم بِأَسْمَآئِهِمْ ۖ فَلَمَّآ أَنۢبَأَهُم بِأَسْمَآئِهِمْ قَالَ أَلَمْ أَقُل لَّكُمْ إِنِّىٓ أَعْلَمُ غَيْبَ ٱلسَّمَـٰوَٰتِ وَٱلْأَرْضِ وَأَعْلَمُ مَا تُبْدُونَ وَمَا كُنتُمْ تَكْتُمُونَ ﴿٣٣﴾

فحينئذ قال الله: { يَا آدَمُ أَنْبِئْهُمْ بِأَسْمَائِهِمْ } أي: أسماء المسميات التي عرضها الله على الملائكة; فعجزوا عنها، { فَلَمَّا أَنْبَأَهُمْ بِأَسْمَائِهِمْ } تبين للملائكة فضل آدم عليهم; وحكمة الباري وعلمه في استخلاف هذا الخليفة، { قَالَ أَلَمْ أَقُلْ لَكُمْ إِنِّي أَعْلَمُ غَيْبَ السَّمَاوَاتِ وَالْأَرْضِ } وهو ما غاب عنا; فلم نشاهده، فإذا كان عالما بالغيب; فالشهادة من باب أولى، { وَأَعْلَمُ مَا تُبْدُونَ } أي: تظهرون { وَمَا كُنْتُمْ تَكْتُمُونَ }
