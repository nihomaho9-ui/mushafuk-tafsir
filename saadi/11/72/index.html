تيسير الكريم الرحمن — السعدي

قَالَتْ يَـٰوَيْلَتَىٰٓ ءَأَلِدُ وَأَنَا۠ عَجُوزٌ وَهَـٰذَا بَعْلِى شَيْخًا ۖ إِنَّ هَـٰذَا لَشَىْءٌ عَجِيبٌ ﴿٧٢﴾

{ قَالَتْ يَا وَيْلَتَى أَأَلِدُ وَأَنَا عَجُوزٌ وَهَذَا بَعْلِي شَيْخًا } فهذان مانعان من وجود الولد { إِنَّ هَذَا لَشَيْءٌ عَجِيبٌ }
