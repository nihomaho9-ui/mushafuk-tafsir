تيسير الكريم الرحمن — السعدي

وَمَا ظَلَمْنَـٰهُمْ وَلَـٰكِن ظَلَمُوٓا۟ أَنفُسَهُمْ ۖ فَمَآ أَغْنَتْ عَنْهُمْ ءَالِهَتُهُمُ ٱلَّتِى يَدْعُونَ مِن دُونِ ٱللَّهِ مِن شَىْءٍ لَّمَّا جَآءَ أَمْرُ رَبِّكَ ۖ وَمَا زَادُوهُمْ غَيْرَ تَتْبِيبٍ ﴿١٠١﴾

{ وَمَا ظَلَمْنَاهُمْ ْ} بأخذهم بأنواع العقوبات { وَلَكِنْ ظَلَمُوا أَنْفُسَهُمْ ْ} بالشرك والكفر، والعناد. { فَمَا أَغْنَتْ عَنْهُمْ آلِهَتُهُمُ الَّتِي يَدْعُونَ مِنْ دُونِ اللَّهِ مِنْ شَيْءٍ لَمَّا جَاءَ أَمْرُ رَبِّكَ ْ} وهكذا كل من التجأ إلى غير الله، لم ينفعه ذلك عند نزول الشدائد. { وَمَا زَادُوهُمْ غَيْرَ تَتْبِيبٍ ْ} أي: خسار ودمار، بالضد مما خطر ببالهم.
