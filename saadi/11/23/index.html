الآية ٢٣

تيسير الكريم الرحمن — السعدي

إِنَّ ٱلَّذِينَ ءَامَنُوا۟ وَعَمِلُوا۟ ٱلصَّـٰلِحَـٰتِ وَأَخْبَتُوٓا۟ إِلَىٰ رَبِّهِمْ أُو۟لَـٰٓئِكَ أَصْحَـٰبُ ٱلْجَنَّةِ ۖ هُمْ فِيهَا خَـٰلِدُونَ ﴿٢٣﴾

يقول تعالى: { إِنَّ الَّذِينَ آمَنُوا } بقلوبهم، أي: صدقوا واعترفوا, لما أمر الله بالإيمان به، من أصول الدين وقواعده. { وَعَمِلُوا الصَّالِحَاتِ } المشتملة على أعمال القلوب والجوارح، وأقوال اللسان. { وَأَخْبَتُوا إِلَى رَبِّهِمْ } أي: خضعوا له، واستكانوا لعظمته، وذلوا لسلطانه، وأنابوا إليه بمحبته، وخوفه، ورجائه، والتضرع إليه. { أُولَئِكَ } الذين جمعوا تلك الصفات { أَصْحَابُ الْجَنَّةِ هُمْ فِيهَا خَالِدُونَ } لأنهم لم يتركوا من الخير مطلبا، إلا أدركوه، ولا خيرا، إلا سبقوا إليه.
