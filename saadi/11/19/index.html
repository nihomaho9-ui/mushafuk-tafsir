هودالآية ١٩

تيسير الكريم الرحمن — السعدي

ٱلَّذِينَ يَصُدُّونَ عَن سَبِيلِ ٱللَّهِ وَيَبْغُونَهَا عِوَجًا وَهُم بِٱلْـَٔاخِرَةِ هُمْ كَـٰفِرُونَ ﴿١٩﴾

ثم وصف ظلمهم فقال: { الَّذِينَ يَصُدُّونَ عَنْ سَبِيلِ اللَّهِ } فصدوا بأنفسهم عن سبيل الله، وهي سبيل الرسل، التي دعوا الناس إليها، وصدوا غيرهم عنها، فصاروا أئمة يدعون إلى النار. { وَيَبْغُونَهَا } أي: سبيل الله { عِوَجًا } أي: يجتهدون في ميلها، وتشيينها، وتهجينها، لتصير عند الناس غير مستقيمة، فيحسنون الباطل ويقبحون الحق، قبحهم الله { وَهُمْ بِالْآخِرَةِ هُمْ كَافِرُونَ }
