الآية ٢٦

تيسير الكريم الرحمن — السعدي

أَن لَّا تَعْبُدُوٓا۟ إِلَّا ٱللَّهَ ۖ إِنِّىٓ أَخَافُ عَلَيْكُمْ عَذَابَ يَوْمٍ أَلِيمٍ ﴿٢٦﴾

{ أَنْ لَا تَعْبُدُوا إِلَّا اللَّهَ } أي: أخلصوا العبادة لله وحده، واتركوا كل ما يعبد من دون الله. { إِنِّي أَخَافُ عَلَيْكُمْ عَذَابَ يَوْمٍ أَلِيمٍ } إن لم تقوموا بتوحيد الله وتطيعوني.
