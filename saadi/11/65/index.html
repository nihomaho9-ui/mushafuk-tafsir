هودالآية ٦٥

تيسير الكريم الرحمن — السعدي

فَعَقَرُوهَا فَقَالَ تَمَتَّعُوا۟ فِى دَارِكُمْ ثَلَـٰثَةَ أَيَّامٍ ۖ ذَٰلِكَ وَعْدٌ غَيْرُ مَكْذُوبٍ ﴿٦٥﴾

{ فَعَقَرُوهَا فَقَالَ } لهم صالح: { تَمَتَّعُوا فِي دَارِكُمْ ثَلَاثَةَ أَيَّامٍ ذَلِكَ وَعْدٌ غَيْرُ مَكْذُوبٍ } بل لا بد من وقوعه.
