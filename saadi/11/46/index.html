الآية ٤٦

تيسير الكريم الرحمن — السعدي

قَالَ يَـٰنُوحُ إِنَّهُۥ لَيْسَ مِنْ أَهْلِكَ ۖ إِنَّهُۥ عَمَلٌ غَيْرُ صَـٰلِحٍ ۖ فَلَا تَسْـَٔلْنِ مَا لَيْسَ لَكَ بِهِۦ عِلْمٌ ۖ إِنِّىٓ أَعِظُكَ أَن تَكُونَ مِنَ ٱلْجَـٰهِلِينَ ﴿٤٦﴾

فـ { قَالَ } الله له: { إِنَّهُ لَيْسَ مِنْ أَهْلِكَ } الذين وعدتك بإنجائهم { إِنَّهُ عَمَلٌ غَيْرُ صَالِحٍ } أي: هذا الدعاء الذي دعوت به، لنجاة كافر, لا يؤمن بالله ولا رسوله. { فَلَا تَسْأَلْنِ مَا لَيْسَ لَكَ بِهِ عِلْمٌ } أي: ما لا تعلم عاقبته،ومآله، وهل يكون خيرا، أو غير خير. { إِنِّي أَعِظُكَ أَنْ تَكُونَ مِنَ الْجَاهِلِينَ } أي: أني أعظك وعظا تكون به من الكاملين، وتنجو به من صفات الجاهلين.
