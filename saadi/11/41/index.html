تيسير الكريم الرحمن — السعدي

وَقَالَ ٱرْكَبُوا۟ فِيهَا بِسْمِ ٱللَّهِ مَجْر۪ىٰهَا وَمُرْسَىٰهَآ ۚ إِنَّ رَبِّى لَغَفُورٌ رَّحِيمٌ ﴿٤١﴾

{ وَقَالَ } نوح لمن أمره الله أن يحملهم: { ارْكَبُوا فِيهَا بِسْمِ اللَّهِ مَجْرَاهَا وَمُرْسَاهَا } أي: تجري على اسم الله، وترسو على اسم الله، وتجري بتسخيره وأمره. { إِنَّ رَبِّي لَغَفُورٌ رَحِيمٌ } حيث غفر لنا ورحمنا، ونجانا من القوم الظالمين.
