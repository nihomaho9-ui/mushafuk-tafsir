الآيات ١٠٤–١٠٥

تيسير الكريم الرحمن — السعدي

وَنَـٰدَيْنَـٰهُ أَن يَـٰٓإِبْرَٰهِيمُ ﴿١٠٤﴾

قَدْ صَدَّقْتَ ٱلرُّءْيَآ ۚ إِنَّا كَذَٰلِكَ نَجْزِى ٱلْمُحْسِنِينَ ﴿١٠٥﴾

الآيات ١٠٤–١٠٥{ وَنَادَيْنَاهُ } في تلك الحال المزعجة، والأمر المدهش: { أَنْ يَا إِبْرَاهِيمُ قَدْ صَدَّقْتَ } أي: قد فعلت ما أمرت به، فإنك وطَّنت نفسك على ذلك، وفعلت كل سبب، ولم يبق إلا إمرار السكين على حلقه { إِنَّا كَذَلِكَ نَجْزِي الْمُحْسِنِينَ } في عبادتنا، المقدمين رضانا على شهوات أنفسهم.
