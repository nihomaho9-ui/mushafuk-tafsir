الآية ٢٣

تيسير الكريم الرحمن — السعدي

مِن دُونِ ٱللَّهِ فَٱهْدُوهُمْ إِلَىٰ صِرَٰطِ ٱلْجَحِيمِ ﴿٢٣﴾

{ وَمَا كَانُوا يَعْبُدُونَ مِنْ دُونِ اللَّهِ } من الأصنام والأنداد التي زعموها،. فاجمعوهم جميعا { فَاهْدُوهُمْ إِلَى صِرَاطِ الْجَحِيمِ } أي: سوقوهم سوقا عنيفا إلى جهنم.
