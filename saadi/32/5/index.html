الآية ٥

تيسير الكريم الرحمن — السعدي

يُدَبِّرُ ٱلْأَمْرَ مِنَ ٱلسَّمَآءِ إِلَى ٱلْأَرْضِ ثُمَّ يَعْرُجُ إِلَيْهِ فِى يَوْمٍ كَانَ مِقْدَارُهُۥٓ أَلْفَ سَنَةٍ مِّمَّا تَعُدُّونَ ﴿٥﴾

{ يُدَبِّرُ الْأَمْرَ } القدري والأمر الشرعي، الجميع هو المتفرد بتدبيره، نازلة تلك التدابير من عند المليك القدير { مِنَ السَّمَاءِ إِلَى الْأَرْضِ } فَيُسْعِدُ بها ويُشْقِي، ويُغْنِي ويُفْقِرُ، ويُعِزُّ، ويُذِلُّ، ويُكرِمُ، ويُهِينُ، ويرفع أقوامًا، ويضع آخرين، ويُنزِّل الأرزاق.{ ثُمَّ يَعْرُجُ إِلَيْهِ } أي: الأمر ينزل من عنده، ويعرج إليه { فِي يَوْمٍ كَانَ مِقْدَارُهُ أَلْفَ سَنَةٍ مِمَّا تَعُدُّونَ } وهو يعرج إليه، ويصله في لحظة.
