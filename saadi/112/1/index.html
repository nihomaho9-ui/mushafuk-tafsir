تيسير الكريم الرحمن — السعدي

بِسْمِ ٱللَّهِ ٱلرَّحْمَـٰنِ ٱلرَّحِيمِ قُلْ هُوَ ٱللَّهُ أَحَدٌ ﴿١﴾

أي { قُلْ } قولًا جازمًا به، معتقدًا له، عارفًا بمعناه، { هُوَ اللَّهُ أَحَدٌ } أي: قد انحصرت فيه الأحدية، فهو الأحد المنفرد بالكمال، الذي له الأسماء الحسنى، والصفات الكاملة العليا، والأفعال المقدسة، الذي لا نظير له ولا مثيل.
