الآية ٩٠

تيسير الكريم الرحمن — السعدي

تَكَادُ ٱلسَّمَـٰوَٰتُ يَتَفَطَّرْنَ مِنْهُ وَتَنشَقُّ ٱلْأَرْضُ وَتَخِرُّ ٱلْجِبَالُ هَدًّا ﴿٩٠﴾

من عظيم أمره أنه { تَكَادُ السَّمَاوَاتُ } على عظمتها وصلابتها { يَتَفَطَّرْنَ مِنْهُ } أي: من هذا القول { وَتَنْشَقُّ الْأَرْضُ } منه، أي: تتصدع وتنفطر { وَتَخِرُّ الْجِبَالُ هَدًّا } أي: تندك الجبال.
