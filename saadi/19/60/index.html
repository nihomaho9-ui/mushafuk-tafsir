الآية ٦٠

تيسير الكريم الرحمن — السعدي

إِلَّا مَن تَابَ وَءَامَنَ وَعَمِلَ صَـٰلِحًا فَأُو۟لَـٰٓئِكَ يَدْخُلُونَ ٱلْجَنَّةَ وَلَا يُظْلَمُونَ شَيْـًٔا ﴿٦٠﴾

ثم استثنى تعالى فقال: { إِلَّا مَنْ تَابَ } عن الشرك والبدع والمعاصي، فأقلع عنها وندم عليها، وعزم عزما جازما أن لا يعاودها، { وَآمَنَ } بالله وملائكته وكتبه ورسله واليوم الآخر، { وَعَمِلَ صَالِحًا } وهو العمل الذي شرعه الله على ألسنة رسله، إذا قصد به وجهه، { فَأُولَئِكَ } الذي جمعوا بين التوبة والإيمان، والعمل الصالح، { يَدْخُلُونَ الْجَنَّةَ } المشتملة على النعيم المقيم، والعيش السليم، وجوار الرب الكريم، { وَلَا يُظْلَمُونَ شَيْئًا } من أعمالهم، بل يجدونها كاملة، موفرة أجورها، مضاعفا عددها.
