تيسير الكريم الرحمن — السعدي

وَلَقَد تَّرَكْنَا مِنْهَآ ءَايَةًۢ بَيِّنَةً لِّقَوْمٍ يَعْقِلُونَ ﴿٣٥﴾

{ وَلَقَدْ تَرَكْنَا مِنْهَا آيَةً بَيِّنَةً لِقَوْمٍ يَعْقِلُونَ } أي: تركنا من ديار قوم لوط، آثارا بينة لقوم يعقلون العِبر بقلوبهم، [فينتفعون بها]، كما قال تعالى: { وَإِنَّكُمْ لَتَمُرُّونَ عَلَيْهِمْ مُصْبِحِينَ وَبِاللَّيْلِ أَفَلَا تَعْقِلُونَ }
