الآية ٤٠

تيسير الكريم الرحمن — السعدي

فَكُلًّا أَخَذْنَا بِذَنۢبِهِۦ ۖ فَمِنْهُم مَّنْ أَرْسَلْنَا عَلَيْهِ حَاصِبًا وَمِنْهُم مَّنْ أَخَذَتْهُ ٱلصَّيْحَةُ وَمِنْهُم مَّنْ خَسَفْنَا بِهِ ٱلْأَرْضَ وَمِنْهُم مَّنْ أَغْرَقْنَا ۚ وَمَا كَانَ ٱللَّهُ لِيَظْلِمَهُمْ وَلَـٰكِن كَانُوٓا۟ أَنفُسَهُمْ يَظْلِمُونَ ﴿٤٠﴾

{ فَكُلا } من هؤلاء الأمم المكذبة { أَخَذْنَا بِذَنْبِهِ } على قدره، وبعقوبة مناسبة له، { فَمِنْهُمْ مَنْ أَرْسَلْنَا عَلَيْهِ حَاصِبًا } أي: عذابا يحصبهم، كقوم عاد، حين أرسل اللّه عليهم الريح العقيم، و { سَخَّرَهَا عَلَيْهِمْ سَبْعَ لَيَالٍ وَثَمَانِيَةَ أَيَّامٍ حُسُومًا فَتَرَى الْقَوْمَ فِيهَا صَرْعَى كَأَنَّهُمْ أَعْجَازُ نَخْلٍ خَاوِيَةٍ } { وَمِنْهُمْ مَنْ أَخَذَتْهُ الصَّيْحَةُ } كقوم صالح، { وَمِنْهُمْ مَنْ خَسَفْنَا بِهِ الْأَرْضَ } كقارون، { وَمِنْهُمْ مَنْ أَغْرَقْنَا } كفرعون وهامان وجنودهما.{ وَمَا كَانَ اللَّهُ } أي: ما ينبغي ولا يليق به تعالى أن يظلمهم لكمال عدله، وغناه التام عن جميع الخلق. { وَلَكِنْ كَانُوا أَنْفُسَهُمْ يَظْلِمُونَ } منعوها حقها التي هي بصدده، فإنها مخلوقة لعبادة اللّه وحده، فهؤلاء وضعوها في غير موضعها، وأشغلوها بالشهوات والمعاصي، فضروها غاية الضرر، من حيث ظنوا أنهم ينفعونها.
