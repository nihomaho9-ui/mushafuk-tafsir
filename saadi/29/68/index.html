الآية ٦٨

تيسير الكريم الرحمن — السعدي

وَمَنْ أَظْلَمُ مِمَّنِ ٱفْتَرَىٰ عَلَى ٱللَّهِ كَذِبًا أَوْ كَذَّبَ بِٱلْحَقِّ لَمَّا جَآءَهُۥٓ ۚ أَلَيْسَ فِى جَهَنَّمَ مَثْوًى لِّلْكَـٰفِرِينَ ﴿٦٨﴾

{ وَمَنْ أَظْلَمُ مِمَّنِ افْتَرَى عَلَى اللَّهِ كَذِبًا } فنسب ما هو عليه من الضلال والباطل إلى اللّه، { أَوْ كَذَّبَ بِالْحَقِّ لَمَّا جَاءَهُ } على يد رسوله محمد صلى اللّه عليه وسلم.ولكن هذا الظالم العنيد، أمامه جهنم { أَلَيْسَ فِي جَهَنَّمَ مَثْوًى لِلْكَافِرِينَ } يؤخذ بها منهم الحق، ويخزون بها، وتكون منزلهم الدائم، الذين لا يخرجون منه.
