تيسير الكريم الرحمن — السعدي

وَلَوْ شَآءَ ٱللَّهُ لَجَعَلَهُمْ أُمَّةً وَٰحِدَةً وَلَـٰكِن يُدْخِلُ مَن يَشَآءُ فِى رَحْمَتِهِۦ ۚ وَٱلظَّـٰلِمُونَ مَا لَهُم مِّن وَلِىٍّ وَلَا نَصِيرٍ ﴿٨﴾

{ و } مع هذا { لَوْ شَاءَ اللَّهُ } لجعل الناس، أي: جعل الناس { أُمَّةً وَاحِدَةً } على الهدى، لأنه القادر الذي لا يمتنع عليه شيء، ولكنه أراد أن يدخل في رحمته من شاء من خواص خلقه.وأما الظالمون الذين لا يصلحون لصالح، فإنهم محرومون من الرحمة، فـ { مَا لَهُمْ } من دون الله { مِنْ وَلِيٍّ } يتولاهم، فيحصل لهم المحبوب { وَلَا نَصِيرٍ } يدفع عنهم المكروه.
