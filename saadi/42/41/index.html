الآية ٤١

تيسير الكريم الرحمن — السعدي

وَلَمَنِ ٱنتَصَرَ بَعْدَ ظُلْمِهِۦ فَأُو۟لَـٰٓئِكَ مَا عَلَيْهِم مِّن سَبِيلٍ ﴿٤١﴾

{ وَلَمَنِ انْتَصَرَ بَعْدَ ظُلْمِهِ } أي: انتصر ممن ظلمه بعد وقوع الظلم عليه { فَأُولَئِكَ مَا عَلَيْهِمْ مِنْ سَبِيلٍ } أي: لا حرج عليهم في ذلك.ودل قوله: { وَالَّذِينَ إِذَا أَصَابَهُمُ الْبَغْيُ } وقوله: { وَلَمَنِ انْتَصَرَ بَعْدَ ظُلْمِهِ } أنه لا بد من إصابة البغي والظلم ووقوعه.وأما إرادة البغي على الغير، وإرادة ظلمه من غير أن يقع منه شيء، فهذا لا يجازى بمثله، وإنما يؤدب تأديبا يردعه عن قول أو فعل صدر منه.
