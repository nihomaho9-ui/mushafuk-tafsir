تيسير الكريم الرحمن — السعدي

أَلَآ إِنَّهُمْ فِى مِرْيَةٍ مِّن لِّقَآءِ رَبِّهِمْ ۗ أَلَآ إِنَّهُۥ بِكُلِّ شَىْءٍ مُّحِيطٌۢ ﴿٥٤﴾

{ أَلَا إِنَّهُمْ فِي مِرْيَةٍ مِنْ لِقَاءِ رَبِّهِمْ } أي: في شك من البعث والقيامة، وليس عندهم دار سوى الدار الدنيا، فلذلك لم يعملوا للآخرة، ولم يلتفتوا لها. { أَلَا إِنَّهُ بِكُلِّ شَيْءٍ مُحِيطٌ } علما وقدرة وعزة.تم تفسير سورة فصلت-بمنه تعالى-
