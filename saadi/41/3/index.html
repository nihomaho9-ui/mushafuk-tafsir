الآية ٣

تيسير الكريم الرحمن — السعدي

كِتَـٰبٌ فُصِّلَتْ ءَايَـٰتُهُۥ قُرْءَانًا عَرَبِيًّا لِّقَوْمٍ يَعْلَمُونَ ﴿٣﴾

ثم أثنى على الكتاب بتمام البيان فقال: { فُصِّلَتْ آيَاتُهُ } أي: فصل كل شيء من أنواعه على حدته، وهذا يستلزم البيان التام، والتفريق بين كل شيء، وتمييز الحقائق. { قُرْآنًا عَرَبِيًّا } أي: باللغة الفصحى أكمل اللغات، فصلت آياته وجعل عربيًا. { لِقَوْمٍ يَعْلَمُونَ } أي: لأجل أن يتبين لهم معناه، كما تبين لفظه، ويتضح لهم الهدى من الضلال، والْغَيِّ من الرشاد.وأما الجاهلون، الذين لا يزيدهم الهدى إلا ضلالاً، ولا البيان إلا عَمًى فهؤلاء لم يُسَقِ الكلام لأجلهم، { سَوَاءٌ عَلَيْهِمْ أَأَنْذَرْتَهُمْ أَمْ لَمْ تُنْذِرْهُمْ لَا يُؤْمِنُونَ } .
