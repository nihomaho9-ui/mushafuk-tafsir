تيسير الكريم الرحمن — السعدي

وَإِذَا تُتْلَىٰ عَلَيْهِ ءَايَـٰتُنَا وَلَّىٰ مُسْتَكْبِرًا كَأَن لَّمْ يَسْمَعْهَا كَأَنَّ فِىٓ أُذُنَيْهِ وَقْرًا ۖ فَبَشِّرْهُ بِعَذَابٍ أَلِيمٍ ﴿٧﴾

ولهذا قال { وَإِذَا تُتْلَى عَلَيْهِ آيَاتُنَا } ليؤمن بها وينقاد لها، { وَلَّى مُسْتَكْبِرًا } أي: أدبر إدبار مستكبر عنها، رادٍّ لها، ولم تدخل قلبه ولا أثرت فيه، بل أدبر عنها { كَأَنْ لَمْ يَسْمَعْهَا } بل { كَأَنَّ فِي أُذُنَيْهِ وَقْرًا } أي: صمما لا تصل إليه الأصوات; فهذا لا حيلة في هدايته.{ فَبَشِّرْهُ } بشارة تؤثر في قلبه الحزن والغم; وفي بشرته السوء والظلمة والغبرة. { بِعَذَابٍ أَلِيمٍ } مؤلم لقلبه; ولبدنه; لا يقادر قدره; ولا يدرى بعظيم أمره، وهذه بشارة أهل الشر، فلا نِعْمَتِ البشارة.
