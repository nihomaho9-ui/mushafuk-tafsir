الآية ٢٨

تيسير الكريم الرحمن — السعدي

مَّا خَلْقُكُمْ وَلَا بَعْثُكُمْ إِلَّا كَنَفْسٍ وَٰحِدَةٍ ۗ إِنَّ ٱللَّهَ سَمِيعٌۢ بَصِيرٌ ﴿٢٨﴾

ثم ذكر عظمة قدرته وكمالها وأنه لا يمكن أن يتصورها العقل فقال: { مَا خَلْقُكُمْ وَلَا بَعْثُكُمْ إِلَّا كَنَفْسٍ وَاحِدَةٍ } وهذا شيء يحير العقول، إن خلق جميع الخلق - على كثرتهم وبعثهم بعد موتهم، بعد تفرقهم في لمحة واحدة - كخلقه نفسا واحدة، فلا وجه لاستبعاد البعث والنشور، والجزاء على الأعمال، إلا الجهل بعظمة اللّه وقوة قدرته.ثم ذكر عموم سمعه لجميع المسموعات، وبصره لجميع المبصرات فقال: { إِنَّ اللَّهَ سَمِيعٌ بَصِيرٌ }
