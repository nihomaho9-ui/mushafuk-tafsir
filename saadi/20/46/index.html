طهالآية ٤٦

تيسير الكريم الرحمن — السعدي

قَالَ لَا تَخَافَآ ۖ إِنَّنِى مَعَكُمَآ أَسْمَعُ وَأَرَىٰ ﴿٤٦﴾

{ قَالَ لَا تَخَافَا } أن يفرط عليكما { إِنَّنِي مَعَكُمَا أَسْمَعُ وَأَرَى } أي: أنتما بحفظي ورعايتي، أسمع أقوالكما، وأرى جميع أحوالكما، فلا تخافا منه، فزال الخوف عنهما، واطمأنت قلوبهما بوعد ربهما.
