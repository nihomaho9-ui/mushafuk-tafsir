الآية ٩٢

تيسير الكريم الرحمن — السعدي

قَالَ يَـٰهَـٰرُونُ مَا مَنَعَكَ إِذْ رَأَيْتَهُمْ ضَلُّوٓا۟ ﴿٩٢﴾

تفسير الآيتين 92 و93 :ـفأقبل موسى على أخيه لائما له، وقال: { يَا هَارُونُ مَا مَنَعَكَ إِذْ رَأَيْتَهُمْ ضَلُّوا* أَلَّا تَتَّبِعَنِ } فتخبرني لأبادر للرجوع إليهم؟ { أَفَعَصَيْتَ أَمْرِي } في قولي { اخْلُفْنِي فِي قَوْمِي وَأَصْلِحْ وَلَا تَتَّبِعْ سَبِيلَ الْمُفْسِدِينَ }
