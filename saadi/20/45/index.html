طهالآية ٤٥

تيسير الكريم الرحمن — السعدي

قَالَا رَبَّنَآ إِنَّنَا نَخَافُ أَن يَفْرُطَ عَلَيْنَآ أَوْ أَن يَطْغَىٰ ﴿٤٥﴾

{ قَالَا رَبَّنَا إِنَّنَا نَخَافُ أَنْ يَفْرُطَ عَلَيْنَا } أي: يبادرنا بالعقوبة والإيقاع بنا، قبل أن تبلغه رسالاتك، ونقيم عليه الحجة { أَوْ أَنْ يَطْغَى } أي: يتمرد عن الحق، ويطغى بملكه وسلطانه وجنده وأعوانه.
