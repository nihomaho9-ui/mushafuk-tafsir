النملالآية ٨٧

تيسير الكريم الرحمن — السعدي

وَيَوْمَ يُنفَخُ فِى ٱلصُّورِ فَفَزِعَ مَن فِى ٱلسَّمَـٰوَٰتِ وَمَن فِى ٱلْأَرْضِ إِلَّا مَن شَآءَ ٱللَّهُ ۚ وَكُلٌّ أَتَوْهُ دَٰخِرِينَ ﴿٨٧﴾

يخوف تعالى عباده ما أمامهم من يوم القيامة وما فيه من المحن والكروب، ومزعجات القلوب فقال: { وَيَوْمَ يُنْفَخُ فِي الصُّورِ فَفَزِعَ } بسبب النفخ فيه { مَنْ فِي السَّمَاوَاتِ وَمَنْ فِي الْأَرْضِ } أي: انزعجوا وارتاعوا وماج بعضهم ببعض خوفا مما هو مقدمة له. { إِلَّا مَنْ شَاءَ اللَّهُ } ممن أكرمه الله وثبته وحفظه من الفزع. { وَكُلٌّ } من الخلق عند النفخ في الصور { أَتَوْهُ دَاخِرِينَ } صاغرين ذليلين، كما قال تعالى: { إِنْ كُلُّ مَنْ فِي السَّمَاوَاتِ وَالْأَرْضِ إِلَّا آتِي الرَّحْمَنِ عَبْدًا } ففي ذلك اليوم يتساوى الرؤساء والمرءوسون في الذل والخضوع لمالك الملك.
