الآية ٥

تيسير الكريم الرحمن — السعدي

أُو۟لَـٰٓئِكَ ٱلَّذِينَ لَهُمْ سُوٓءُ ٱلْعَذَابِ وَهُمْ فِى ٱلْـَٔاخِرَةِ هُمُ ٱلْأَخْسَرُونَ ﴿٥﴾

( أُولَئِكَ الَّذِينَ لَهُمْ سُوءُ الْعَذَابِ ) أي: أشده وأسوأه وأعظمه، ( وَهُمْ فِي الآخِرَةِ هُمُ الأخْسَرُونَ ) حصر الخسار فيهم لكونهم خسروا أنفسهم وأهليهم يوم القيامة وخسروا الإيمان الذي دعتهم إليه الرسل.
