تيسير الكريم الرحمن — السعدي

وَإِنَّهُۥ لَهُدًى وَرَحْمَةٌ لِّلْمُؤْمِنِينَ ﴿٧٧﴾

{ وَإِنَّهُ لَهُدًى } من الضلالة والغي والشبه { وَرَحْمَةٌ } تنثلج له صدورهم وتستقيم به أمورهم الدينية والدنيوية { لِلْمُؤْمِنِينَ } به المصدقين له المتلقين له بالقبول المقبلين على تدبره المتفكرين في معانيه، فهؤلاء تحصل لهم به الهداية إلى الصراط المستقيم والرحمة المتضمنة للسعادة والفوز والفلاح.
