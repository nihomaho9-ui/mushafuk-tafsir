الآية ١٦

تيسير الكريم الرحمن — السعدي

أُو۟لَـٰٓئِكَ ٱلَّذِينَ نَتَقَبَّلُ عَنْهُمْ أَحْسَنَ مَا عَمِلُوا۟ وَنَتَجَاوَزُ عَن سَيِّـَٔاتِهِمْ فِىٓ أَصْحَـٰبِ ٱلْجَنَّةِ ۖ وَعْدَ ٱلصِّدْقِ ٱلَّذِى كَانُوا۟ يُوعَدُونَ ﴿١٦﴾

{ أُولَئِكَ } الذين ذكرت أوصافهم { الَّذِينَ نَتَقَبَّلُ عَنْهُمْ أَحْسَنَ مَا عَمِلُوا } وهو الطاعات لأنهم يعملون أيضا غيرها. { وَنَتَجاوَزُ عَنْ سَيِّئَاتِهِمْ } فِي جملة { أَصْحَابُ الْجَنَّةِ } فحصل لهم الخير والمحبوب وزال عنهم الشر والمكروه.{ وَعْدَ الصِّدْقِ الَّذِي كَانُوا يُوعَدُونَ } أي: هذا الوعد الذي وعدناهم هو وعد صادق من أصدق القائلين الذي لا يخلف الميعاد.
