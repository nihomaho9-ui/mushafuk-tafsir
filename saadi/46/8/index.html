تيسير الكريم الرحمن — السعدي

أَمْ يَقُولُونَ ٱفْتَرَىٰهُ ۖ قُلْ إِنِ ٱفْتَرَيْتُهُۥ فَلَا تَمْلِكُونَ لِى مِنَ ٱللَّهِ شَيْـًٔا ۖ هُوَ أَعْلَمُ بِمَا تُفِيضُونَ فِيهِ ۖ كَفَىٰ بِهِۦ شَهِيدًۢا بَيْنِى وَبَيْنَكُمْ ۖ وَهُوَ ٱلْغَفُورُ ٱلرَّحِيمُ ﴿٨﴾

{ أَمْ يَقُولُونَ افْتَرَاهُ } أي: افترى محمد هذا القرآن من عند نفسه فليس هو من عند الله. { قُلْ } لهم: { إِنِ افْتَرَيْتُهُ } فالله علي قادر وبما تفيضون فيه عالم، فكيف لم يعاقبني على افترائي الذي زعمتم؟فهل { تَمْلِكُونَ لِي مِنَ اللَّهِ شَيْئًا } إن أرادني الله بضر أو أرادني برحمة { كَفَى بِهِ شَهِيدًا بَيْنِي وَبَيْنَكُمْ } فلو كنت متقولا عليه لأخذ مني باليمين ولعاقبني عقابا يراه كل أحد لأن هذا أعظم أنواع الافتراء لو كنت متقولا، ثم دعاهم إلى التوبة مع ما صدر منهم من معاندة الحق ومخاصمته فقال: { وَهُوَ الْغَفُورُ الرَّحِيمُ } أي: فتوبوا إليه وأقلعوا عما أنتم فيه يغفر لكم ذنوبكم ويرحمكم فيوفقكم للخير ويثيبكم جزيل الأجر.
