الآية ٨٣

زاد المسير — ابن الجوزي

لَقَدْ وُعِدْنَا نَحْنُ وَءَابَآؤُنَا هَـٰذَا مِن قَبْلُ إِنْ هَـٰذَآ إِلَّآ أَسَـٰطِيرُ ٱلْأَوَّلِينَ ﴿٨٣﴾

قَوْلُهُ تَعالى: ﴿قَلِيلا ما تَشْكُرُونَ﴾ قالَ المُفَسِّرُونَ: يُرِيدُ: أنَّهم لا يَشْكُرُونَ أصْلًا. قَوْلُهُ تَعالى: ﴿ذَرَأكم في الأرْضِ﴾؛ أيْ: خَلَقَكم مِنَ الأرْضِ. قَوْلُهُ تَعالى: ﴿وَلَهُ اخْتِلافُ اللَّيْلِ والنَّهارِ﴾؛ أيْ: هو الَّذِي جَعَلَهُما مُخْتَلِفَيْنِ يَتَعاقَبانِ ويَخْتَلِفانِ في السَّوادِ والبَياضِ. ﴿أفَلا تَعْقِلُونَ﴾ ما تَرَوْنَ مِن صُنْعِهِ ؟ وما بَعْدُ هَذا ظاهِرٌ إلى قَوْلِهِ: ﴿قُلْ لِمَنِ الأرْضُ﴾؛ أيْ: قُلْ لِأهْلِ مَكَّةَ المُكَذِّبِينَ بِالبَعْثِ: لِمَنِ الأرْضُ، ﴿وَمَن فِيها﴾ مِنَ الخَلْقِ، ﴿إنْ كُنْتُمْ تَعْلَمُونَ﴾ بِحالِها، ﴿سَيَقُولُونَ لِلَّهِ﴾ قَرَأ أبُو عَمْرٍو: ( لِلَّهِ ) بِغَيْرِ ألِفٍ هاهُنا وفي اللَّذَيْنِ بَعْدَها بِألِفٍ. وقَرَأ الباقُونَ: ( لِلَّهِ ) في المَواضِعِ الثَّلاثَةِ. وقِراءَةُ أبِي عَمْرٍو عَلى القِياسِ. قالَ الزَّجّاجُ: ومَن قَرَأ: ( سَيَقُولُونَ اللَّهُ ) فَهو جَوابُ السُّؤالِ، ومَن قَرَأ: ( لِلَّهِ ) فَجَيِّدٌ أيْضًا؛ لِأنَّكَ (p-٤٨٧)إذا قُلْتَ: مَن صاحِبُ هَذِهِ الدّارُ ؟ فَقِيلَ: لِزَيْدٍ، جازَ؛ لِأنَّ مَعْنى ( مَن صاحِبُ هَذِهِ الدّارِ ؟ ): لِمَن هي. وقالَ أبُو عَلِيٍّ الفارِسِيُّ: مَن قَرَأ: ( لِلَّهِ ) في المَوْضِعَيْنِ الآخَرَيْنِ، فَقَدْ أجابَ عَلى المَعْنى دُونَ ما يَقْتَضِيهِ اللَّفْظُ. وقَرَأ سَعِيدُ بْنُ جُبَيْرٍ، وأبُو المُتَوَكِّلِ، وأبُو الجَوْزاءِ: ( سَيَقُولُونَ اللَّهُ ) ( اللَّهُ ) ( اللَّهُ ) بِألِفٍ فِيهِنَّ كُلِّهِنَّ. قالَ أبُو عَلِيٍّ الأهْوازِيُّ: وهو في مَصاحِفِ أهْلِ البَصْرَةِ بِألِفٍ فِيهِنَّ. قَوْلُهُ تَعالى: ﴿قُلْ أفَلا تَذَكَّرُونَ﴾ فَتَعْلَمُونَ أنَّ مَن قَدَرَ عَلى خَلْقِ ذَلِكَ ابْتِداءً، أقْدَرُ عَلى إحْياءِ الأمْواتِ.
